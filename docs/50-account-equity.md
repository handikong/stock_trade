# 每日账户净值与当日盈亏

在两个市场各自的「持仓总览」查看账户估算净值和当日盈亏。点击净值卡打开走势，可切换最近 7、30、365 个日历日，拖动选择器查看某天的金额，或展开逐日记录。

持仓表的「今日盈亏」按当前登记股数或份数乘以价格相对前一交易日收盘的变动估算，百分比为价格变动除以前收。美股盘中使用有效的 IEX 成交。盘后及 A 股使用相邻两个交易日的有效收盘价，日期见价格列。缺相邻收盘、已识别拆股或盘中报价尺度待核对时留空。金额未计已实现盈亏、费用和分红。美股盘中，顶部「盘中持仓盈亏」同步汇总，等所有持仓的有效现价和前收齐全才显示。

美股使用已有的账户现金和累计外部净入金。A 股在持仓页点击「填写人民币现金」，录入券商总现金和累计净入金。累计净入金始终使用同一起点。转入增加累计额，转出扣减累计额。成交和分红反映在持仓或总现金里。人工更新股数或份数后，同时重新确认总现金。净值采集发现数量已变化但现金记录还是旧版本时，先等待对账。

净值为登记的总现金加上全部登记持仓按对应交易日有效收盘计算的市值。无持仓且已填写现金时按现金账户估算。每日盈亏等于当日净值减去前一交易日净值，再减去两日之间的外部净入金。首日、前一交易日缺快照或累计净入金口径缺失时，当日盈亏留空。估算以本地登记和市场收盘为依据，现金与持仓应和券商同步。

## 保存与补录

后台在美股日线窗口（北京时间默认 06:00 至 10:00）与 A 股日线窗口（交易日默认 15:35 至 21:00）分别入队。自动任务独立于关注池、策略和飞书。缺少目标日收盘或现金时保留历史，任务状态注明失败原因。失败超过 15 分钟且仍在窗口内时最多自动重试一次。

趋势图中可以点「保存最近收盘」手动采集。按钮只允许标记最近已完成的交易日，下一场交易开盘前可修订同一收盘点。采集复用目标日缓存，缺少的持仓行情按现有 yfinance 流程更新。系统从部署后积累快照，历史日期缺口不补造。图中连续的交易日相连，缺少交易日记录处断开。

快照按市场和交易日唯一保存，USD 与 CNY 分开。记录所用现金版本、外部净入金、持仓数量、持仓版本和行情快照 ID。访问趋势图只读已有记录。

## 用户验收

- EQ01 美股沿用原账户现金。A 股填写人民币现金后，分别核对各自净值和日期，核对现金账户及缺报价场景。
- EQ02 保留前后两个连续交易日快照。若净值增加 1,200，期间外部净入金增加 1,000，当日盈亏应为 200。首日及缺前一交易日记录时盈亏留空。
- EQ03 点击净值卡切换近一周、近一月和近一年。核对折线、键盘选择日期和逐日明细，检查缺失交易日的断点。
- EQ04 重复保存最近收盘，核对同一市场同一交易日只有一条。开盘后再尝试标记上一日，核对拒绝提示。
- EQ05 修改持仓数量但暂时不确认现金，核对快照被拦截。按券商余额保存现金后，在允许的窗口内重新采集。
- EQ06 在计划任务状态核对两市场独立运行、遇缺价失败和窗口内重试。
- EQ07 例如 100 股，前收 283.93 USD，盘中价 291.99 USD，今日盈亏应显示 +806.00 USD、2.84%。核对顶部盘中持仓合计、缺报价留空、A 股相邻收盘比较及收盘净值历史。
