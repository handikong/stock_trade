## 两期财报是否足够

两个当季数据本身不足以构造完整TTM或可靠的一年预测。最近两期财报原文及研究事实的范围保持不变；估值另从已归档SEC批量原始数据复用上一完整财年、上年同期及历史披露版本，不下载更多定期报告。补充期间、来源和假设列在`valuation_draft`。历史PE还需较早盈利申报，不能声称整个估值只用两个当季数据。

TTM流量=上一完整财年＋本年累计−上年同期；概念、单位与期间必须匹配。加权稀释股数先按各期间天数还原权重，再构造TTM平均值。TTM EPS=派生净利润/加权稀释股数，不将累计EPS直接相减，也不把两季年化。归属普通股利润、稀释调整与一次性损益仍需复核。

当前PE=最近完整收盘价/最新已披露派生TTM EPS。历史PE匹配各历史价格日期之前已申报的盈利；只有申报日期而无时分秒时，保守到下一交易日使用。输入来自当前SEC事实档案及披露日期，不代表完整点时回测数据库。窗口内存在拆股时停止自动草稿，避免价格与股数口径混用。

## 可配置的草稿假设

文件：`config/valuation-policy.json`，可通过`VALUATION_POLICY_FILE`更换。结果始终为未确认`draft`，不自动成为正式估值或交易许可。原`--valuation`手工假设入口保留。

| 项目 | 当前做法 | 局限 |
| --- | --- | --- |
| PE | 最近252个完整交易日匹配当时可知的TTM，取25/50/75分位；至少120个样本 | 历史定价不证明未来合理PE或价格覆盖概率 |
| 首年增长 | 最近可比累计营收同比＋−5/0/+5个百分点扰动，受增长边界约束 | 机械外推，不是公司指引或分析师EPS预测 |
| 目标EPS | 利润率、税率和股数保持基线，桥接财务期末到估值日，再投影至一年后TTM | 尚未正常化一次性损益，不把FY1直接当作NTM |
| DCF经营路径 | TTM经营利润、税率、DA、capex比例为基线，5年增长线性收敛至终值增长 | 利润率与投入比例不变属于假设 |
| 营运资本 | 贸易应收＋存货−贸易应付占营收比例，按未来营收变化计算增量 | 未覆盖全部经营资产负债，仅为部分项目代理 |
| 股份支付 | 保留在EBIT费用，不加回，股数固定 | 未建回购、期权和稀释路径 |
| 权益桥接 | 加现金等价物，减长短期债务及商业票据，其他优先索取权暂设0 | 全部现金视为非经营现金，未扣经营所需现金；证券等其他资产未计，索取权需核对 |
| 一年后状态 | 现金、债务、股数保持基线，不累加已分配现金流 | 一年后价格不含期间分红，不代表股东总回报 |
| WACC | 按股票及SEC SIC匹配有来源配置，暂无匹配则保留DCF缺口 | 不能为所有股票套AAPL参数 |

AAPL暂以2026年1月Damodaran美国Computers/Peripherals行业资本成本9.71%作代理，保守/乐观加减1个百分点。不是AAPL自身最新WACC估计，来源、日期与说明保留在配置。[来源](https://pages.stern.nyu.edu/adamodar/New_Home_Page/datafile/wacc.html)

上述参数是可修改的研究敏感性模板。DCF分别输出今日内在价值、一年后重新折现剩余现金流并使用目标资产负债/股数的价格；不简单把今日价值乘收益率。模型不平均为一个精准目标价。

## 调用与缓存

普通`stock-research AAPL`和网页刷新共用生成流程。`--cached`仍只读，不联网、不重算、不写估值。输入键含来源快照、算法、配置与估值日；变化使旧草稿过期。未知币种、行情不新鲜、财务过旧、TTM缺失、盈利非正或不适用行业会明确拒绝或保留缺口。

`valuation_draft`保存当前PE、目标日期、模型区间、配置、基线与证据、历史PE样本及限制；`valuation`保存完整可复算输入。手工模型与历史草稿不删除。Docker镜像包含`config/`，Compose挂载宿主配置，供用户修改。
