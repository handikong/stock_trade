# 命令行完整回测报表

日期：2026-10-31。用户澄清客户端是**命令行**，暂不开发页面。新增默认终端表格及公共绩效归因，不改变模拟买卖、仓位或策略结果。

## 1. 默认三张表

1. **账户绩效**：初始资金、期末净值、净收益、区间收益率、最大日终回撤和金额、回撤高点/低点/修复日、夏普率、年化收益估算、年化波动率、索提诺率、卡玛率、胜率、盈利因子、平均盈亏比、平均盈亏、连胜/连亏、现金与资金投入比例。
2. **各股票累计盈亏**：每股已平笔数、已平仓净利、未平仓盈亏、总净利、手续费和已平仓胜率；包含零交易股票及合计行。
3. **买卖明细**：每笔股票、策略、买入日期/价格、股数、卖出日期/价格、费用、净盈亏、成本收益率、已平/未平状态，按买入日期排序。

默认不刷出大段模型说明；--details展开参数、跳过原因和限制，--json仍保留所有数据与原信号日期。中文按双列宽对齐、数值右对齐，无ANSI颜色控制码，支持重定向为文本。明细较宽，应在约120列的终端查看。

所有金额沿用Decimal计算；显示时各行独立四舍五入，因此可有分币级显示差异，合计用未舍入值。已平净利、未平盈亏均包含各自应收分红；未平不预扣未来卖出费。逐股未舍入总净利须与账户净收益对平，否则拒绝出表。未平仓保留卖出日期/价为空，不补造退出。

## 2. 命令

```bash
# 新回测默认直接输出三张终端表，并保存完整JSON
.venv/bin/stock-backtest --cash 10000

# 已有结果直接出表，不重新模拟交易
.venv/bin/stock-backtest --report data/MG7-backtest-10000-20261031.json

# 读取已有结果，另存包含补充统计的JSON；不覆盖原件
.venv/bin/stock-backtest --report data/MG7-backtest-10000-20261031.json --output data/my-mg7-report.json

# 仅改变指标统计假设，不改变交易结果；0.02是2%而非2
.venv/bin/stock-backtest --report data/MG7-backtest-10000-20261031.json --risk-free-rate 0.02

.venv/bin/stock-backtest --report data/MG7-backtest-10000-20261031.json --details
```

--report不能与本金、股票、日期或策略参数修改同时使用，防止仅改标签而没有重跑交易。只读模式不传--output就不写结果；有--output时新建文件，拒绝覆盖。读取已有增强报告时默认沿用其已保存统计假设，显式--risk-free-rate/--annualization-sessions才覆盖。

回测配置新增risk_free_annual（默认0，研究假设）和annualization_sessions（默认252）；旧配置自动补默认。前者只影响夏普/索提诺，不能假装是已获取的国债收益率，也不改变模拟现金利息。

## 3. 统一统计口径

公共`backtest_metrics.enrich_report`由CLI和以后客户端共用。输出analytics.algorithm=`daily-equity-performance-v1`，包含methods、performance、by_symbol、trade_details、daily_returns。

- 日收益：E_t/E_(t-1)−1，首个交易日以前一值=初始资金，包含现金日、未实现市值和分红应收；不只对有交易日期计算。
- 日无风险收益：(1＋无风险年利率)^(1/年化交易日)−1。
- 夏普率：日超额收益均值/日收益**样本标准差（n−1）**×sqrt(年化交易日)。数据来源与定义参考[William F. Sharpe原文](https://web.stanford.edu/~wfsharpe/art/sr/SR.htm)。平方根年化采用常见周期缩放假设，未额外校正收益自相关，不代表预测显著性。
- 年化波动率：日收益样本标准差×sqrt(年化交易日)。
- 年化收益估算：(末值/初值)^(年化交易日/样本交易日)−1。仅短样本折算，不将其当作实际全年收益或未来承诺。
- 索提诺率：日超额收益均值/全样本下行半偏差×sqrt(年化交易日)；半偏差=sqrt(mean(min(超额日收益,0)^2))，分母包含全部样本日。
- 卡玛率：年化收益估算/最大日终回撤。
- 最大回撤：从初始资金锚点起计算净值高点到后续日终的最大百分比跌幅；另列最大金额跌幅。两种最大值不保证出现在同一天。
- 回撤区间：最大百分比回撤对应高点、低点；之后首次恢复该高点为修复日，尚未恢复明确显示。初始资金高点无交易日期时标“初始资金”。
- 胜率/盈利因子/平均盈亏比只看已结束交易；盈利因子=盈利合计/亏损绝对值合计，平均盈亏比=平均盈利/平均亏损绝对值。
- 每股总净利=已平仓含费/分红净利＋未平仓含买费/分红盈亏。没有给每股虚构时间加权收益率；明细收益率为该笔成本回报。

样本不足、零标准差、无下行或无亏损等分母不适用时返回null并显示“—”，不填0、无穷或高分。净值非正拒绝当前年化算法。没有比较基准数据，不生成Alpha、Beta、信息比率或超额指数收益。
