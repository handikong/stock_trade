## 2. 账户净值、现金流和本金保护

### EQ-01 账户口径

账户净值 E = 所有现金余额 + 持仓按有效标记价计算的市值 + 可核实应收款 − 负债 − 尚未计入账本的应付费用，统一换算到配置的账户基准币种。同一费用不得重复扣除。浮盈亏计入 E。

报价币种、基准币种和汇率时点必须显式保存。默认范围为现金多头；导入发现融资/空头等范围外风险时仍纳入估值和风险报告，冻结相关新增风险，要求对账处理，不能忽略该持仓。

实际现金、可用现金、已预约现金、可用于新买入的券商购买力分别展示。没有券商购买力数据时，使用保守的已确认可用现金；不得默认卖出后全部资金立即可用。交易结算规则由账户/券商能力与市场适配器提供。

### EQ-02 固定初始亏损预算（第一版默认算法）

定义：

- B0：用户确认的参考本金，必须大于零。
- t0：风险基准生效时间。导入前的损益是否包含在基准中由用户预览后设置。
- r：允许相对参考本金亏损的比例。
- C(t)：t0 之后净外部资金流入，入金为正、出金为负。
- E*(t) = E(t) − C(t)：剔除外部资金流影响的净值。
- 本金亏损 L(t) = max(0, B0 − E*(t))。
- 初始亏损预算 R0 = B0 × r。
- 预算使用率 U(t) = L(t) / R0（r=0 的特殊处理见配置文档）。
- 账户本金保护参考线 F(t) = B0 × (1 − r) + C(t)。
- 到参考线的净值缓冲 H(t) = E(t) − F(t)。

利润、分红、利息、交易费用和交易税费属于投资结果，不作为外部入金/出金。证券转入/转出按生效时公允价值记外部现金流，原税务成本另存。相同证券跨内部资金池划转不是外部资金流。

例：B0=100,000，r=5%，C=0，则 R0=5,000，F=95,000。E 涨至 120,000 后跌到 110,000，不触发本金亏损。随后入金 10,000，则 F=105,000，原有 5,000 的初始亏损预算不自动扩大。

这是“固定初始亏损预算”的明确语义，不等于“每次追加本金都多允许亏 5%”。后者可扩展为另一算法，但必须显式选择并预览，第一版不混用。

### EQ-03 最高点回撤与基准变更

从最高净值回撤是独立展示指标。需要扣除外部现金流影响，使用现金流事件切分的单位净值与历史高点，不能直接比较含入金的账户余额。

单位净值算法：初始化时净值 E0>0，单位数 N0=E0、单位价格 V0=1；没有外部流时 V=E/N；外部流 C_event 在发生前单位价 V_before 下增加/减少单位数 ΔN=C_event/V_before，事件后单位价格保持不变。最高单位价格 V_high 只由有效估值更新，最高点回撤率 D=1−V/V_high。启用回撤比例 d 时，当前回撤参考线 F_peak=N×V_high×(1−d)，预算使用率 U_peak=(N×V_high−E)/(N×V_high×d)，下限取0。需要事件前可靠估值；缺失则标记回撤指标不可靠、不能批准新增风险，不能以粗略日终估值伪装精确现金流校正。

启用 both 时，有效保护线为 max(F, F_peak)，风险状态按两种预算使用率中更高者确定；只启用一种时不偷偷应用另一种的限制。r 或 d 为0且对应保护启用时，新增风险预算为0，避免除零。

风险模式可选：本金保护 / 最高点回撤保护 / 两者同时。最高点模式需完整单位净值基准；缺少历史数据从明确的初始化日计算，不能补造历史高点。两者同时开启时取更严格的可用预算与状态。

本金保护模式不因盈利、亏损、年度切换自动重设 B0 或 t0。重设属于显式配置变更，必须展示此前亏损及变更后的风险空间；不得删除旧基准或审计记录。出金使参考线非正或账户结构无效时，标记需重新评估，不能用负数预算继续开仓。

### RSK-01 分级风险状态

按配置的预算使用率阈值进入 NORMAL → WATCH → RESTRICTED → DEFENSIVE → BREACHED；相邻阈值必须严格有序。BREACHED 对应所启用风险保护条件已达到/越过阈值。

| 状态 | 系统行为 |
| --- | --- |
| NORMAL | 在其他规则均满足时可产生入场计划 |
| WATCH | 提醒剩余预算，按配置缩减新交易风险额度 |
| RESTRICTED | 不激活新增风险计划；取消未执行部分的资金预约；已有持仓复查 |
| DEFENSIVE | 生成按风险贡献排序的减仓/退出草稿，高优先级提醒；不虚构已完成减仓 |
| BREACHED | 记录突破参考线、继续提醒和风险处置；禁止系统认可新增风险，不自动重置本金 |

风险升级立即生效；恢复需满足滞回阈值、冷静期和数据健康条件，防止价格抖动反复放行。阈值、折减系数、恢复条件均配置化。默认行为是越接近预算边界越保守，而非等到亏损限额才首次提醒。

5% 等数值是目标预算，不是保证亏损的硬上限。盘中提醒失联、隔夜跳空、停牌、流动性和成交偏差可能越线。第一版每次展示保护线时必须同时显示数据时点与“仅提醒/人工执行”的模式。

### RSK-02 风险额度与仓位计算

每个候选同时受以下约束，取最小可用额度：单笔风险预算、账户剩余计划风险、资金池可用风险、本金/回撤缓冲减去保留缓冲、单股金额上限、行业/因子暴露、现金与可用购买力、流动性容量。

对多头新买入：每股计划损失 d = 最不利允许买入价 − 有效风险退出参考价 + 每股滑点与变动费用，d 必须为正。固定费用另外扣除；按可成交数量步长向下取整后再次校验全部约束。

数量 q ≤ (可分配风险金额 − 固定成本) / d，同时满足金额/现金/集中度约束。小于最小交易单位则跳过，不为凑单放宽失效价。高波动或距离失效位较远应通过更小仓位适配，而非机械收紧到日常噪声范围。

单笔风险计算基数可选参考本金或当前净值，必须记录。即使盈利增加了本金缓冲，单笔、总仓位和压力测试限制仍然有效。

### RSK-03 持仓与待执行计划的共同预算

已有仓位的计划风险从**当前标记价**到当前有效风险退出参考价计算，不能只看买入成本；盈利仓位回吐也会消耗当前净值缓冲。长期基本面持仓同样需要明确风险退出参考或保守损失情景，否则其风险是未知，不是零。

总计划风险包括所有资金池、待分类导入持仓、已激活但未成交的计划剩余数量、在途订单（将来接券商时）和费用。多个计划可能同时触发，必须在数据库事务内预约预算，不能各自使用同一份余额。

计划风险之和只是一个评估维度。另做市场下跌、行业集中下跌、个股隔夜缺口、ETF 成分重叠的压力情景；压力损失与计划退出风险分别比较阈值，不能相加成重复计数，也不能认为所有持仓一定能按退出价成交。情景幅度由配置提供，无有效情景参数时不得标记“压力测试通过”。

数据过期/缺失使风险无法可靠计算时，禁止新增风险计划的激活，继续显示最近可信估值及时间，并发出数据故障提示；不得以旧数据保证账户安全。

## 3. 资金池、持仓数量与迁移

- **BOOK-01 双资金池**：核心池与机动池共用总账户风险。机动预算是上限，不是目标仓位；核心预算也包含现金。机动比例当前偏好可预填 10%，需设置后生效。
- **BOOK-02 金额与风险分别限制**：资金池必须同时拥有最大投入金额/占比、最大计划风险、最大持仓数量。不能把“允许用 10% 资金”解释为“允许亏掉总本金 10%”。
- **BOOK-03 动态持股数**：持股上限是配置约束；实际数量由合格机会、每笔风险、现金和集中度决定。没有机会就保持现金，不按资金规模强制凑满只数。
- **BOOK-04 合并暴露**：同一证券跨资金池合并校验证券总上限；通过 ETF 的成分/行业暴露一并展示。ETF 成分未知或陈旧时标明覆盖率，并使用保守集中度规则；不能把多只同主题 ETF 当成充分分散。
- **BOOK-05 禁止损失迁移**：不得通过把机动亏损仓改为长期仓、增加机动本金或转入资金而抹去历史亏损。允许有记录的策略迁移，但需新研究/新计划、保留原交易段绩效，且不能覆盖已触发的账户风险处置或到期规则。
- **BOOK-06 不自动补亏**：机动预算的补充/重新分配有预设复查周期及独立变更记录；不因刚亏损就在盘中自动从核心池补足。预算基数固定/随净值变化由配置明确。
- **BOOK-07 现有持仓**：导入后先进入待评估状态；资金与风险立即计入账户。按原始成交日期、研究信息和风险情况建立迁移计划。成本不明不妨碍按现值计风险，但必须标记历史盈亏未知。不能为了接入系统而默认全部卖出重买。
- **BOOK-08 仓位放大**：任何加仓都是新增风险计划，重新计算整体风险。核心策略不能因浮亏而自动补仓；机动策略可使用预先定义、总风险受限的分批计划，不能临时新增无限摊平档位。

资金池设独立的内部现金/证券账本：初始分配、后续显式内部划转、成交现金流、收益与费用均记入所属池。现金不足时不能仅因账户总现金充足就默默借用另一池；资金池现金之和加未分配现金与账户现金必须可对账。机动从12,500亏损退出后仅剩11,500，其可用池资金就是11,500，不自动恢复到12,500。持仓快照迁移可分配初始资产，不制造虚拟买卖。

资金池“新增投入上限”的占用按当前持仓剩余投入成本（含已分摊买入费用）加未执行买入预约计算；成本未知时采用保守现值并标记。退出只释放对应剩余投入占用，现金回收使用实际卖出净额。另以当前市值加预约检查证券、行业和总风险资产上限，因此盈利不被误记为新投入，但不会漏掉市值集中风险。外部入金先进入未分配现金，分配到某池属于显式内部划转。

## 4. 计划与执行状态

### PLAN-01 必填内容

计划必须包含：账户/资金池/证券、策略与配置版本、生成时点、研究及相反证据、入场触发公式、价格区间及最高接受价、最早有效时点/失效时点、最多数量与分批规则、资金/风险预约、风险退出参考、正常持有与退出条件、财报/事件政策、提醒模式、数据时点与来源。

长期计划不要求固定盈利目标；但必须有继续持有依据、复查周期、逻辑失效和风险退出。用户自己填写的研究判断允许使用，但标记为人工判断并保留证据，不得冒充机器已验证事实。

### PLAN-02 生命周期

DRAFT（草稿）→ VALIDATED（完整且评估通过）→ ARMED（用户选择执行意向、原子预约额度）→ TRIGGERED（条件提醒已产生）。失效可转 EXPIRED / CANCELLED / INVALIDATED；草稿/校验态不预约额度。

成交是独立追加事件，可使已激活计划进入 PARTIALLY_FILLED / FILLED；实际交易可能没有等到提醒就发生，不能因此丢弃成交。任何状态下导入成交都必须入账，再检查计划关联与偏离情况。未关联成交标记 UNPLANNED，不能追溯伪造 ARMED 时间。

计划有部分成交后过期，只释放未成交部分预约；已成交部分继续作为真实持仓管理。取消计划不等于卖出持仓。

持仓管理状态独立于计划：IMPORTED_REVIEW（导入待评估）、HELD_VALID（按计划持有）、REVIEW_REQUIRED（逻辑/数据待复查）、EXIT_REQUIRED（触发退出条件）、OVERDUE（机动期限已到且仍持有）、CLOSED（真实数量归零）。退出提醒不能把状态直接改为 CLOSED；数据未知使持仓转待复查，但仍计总风险。EXIT_REQUIRED 的触发依据被事实修正或有效计划修订改变时可重新评估，必须保留原事件及原因。

### PLAN-03 盘中约束与风险退出

- 使用完整收盘数据生成的计划最早在下一适用交易时段生效。事件型风险通知可以在获取事件后产生。
- 触发后行情超过最高接受价、数据过期、条件失效或风险预算变动，必须重新校验，不能提示无条件追入。
- 盘中新热点默认研究候选；临时新增风险计划需按配置的例外流程登记理由与冷静期，不能静默绕过规则。例外不能绕过账户风险、币种/现金有效性及数据完整性。
- 止损后换股需要已有有效新计划并满足冷静期；“刚卖出释放资金”不能单独触发买入。
- 保护性卖出、紧急减仓和事实性成交导入不被开仓冷静期拦截；需保存原因和成交记录。卖出数量不能超过可用持仓，避免变成意外卖空。

### PLAN-04 配置与计划变更

修改前展示风险、预算、退出条件和受影响计划。更严格的账户限制对所有现存计划重新校验；更宽松的配置不会自动扩展已预约数量或追价上限。改变入场/退出逻辑需生成计划修订并重新验证，旧版本只读。

普通修改立即/下个交易日生效可选；放宽风险或扩大仓位默认下个交易日生效，用户可显式立即生效并记录理由和影响确认。任何修改不得改写历史成交、历史规则版本和旧绩效。

执行时要求同时满足当前全局限制和计划有效版本。界面必须展示当前采用的退出条件，不能旧计划与新规则各算一套且不说明。

## 5. 股票池、候选雷达与研究

### UNI-01 可交易范围与排除规则

第一版计划范围是美股交易所上市的普通股和普通非杠杆 ETF，多头现金交易。普通股、ADR、行业 ETF、宽基 ETF 必须有独立类型；不支持或无法可靠分类的类型仅能研究/导入，不自动通过开仓筛选。

“不买妖股/仙股”实现为规则集合：证券类型、最低价格、最低市值、近期中位日成交金额、买卖价差、上市历史长度、异常波动/涨幅、停牌或退市状态、持续经营/财报异常、重大事件。各数值阈值与观察窗口可配置，展示命中项，不使用无法解释的“妖股评分”。价格低不自动代表基本面差，异常上涨也不自动证明操纵。

证券类型与基础数据缺失、已停牌/不可交易属于无法激活新计划的条件。可调筛选阈值允许用户通过新配置调整，不能由 AI 临时豁免。已持仓证券新触发排除项时生成复查/风险提示，而非伪造可成交的立即清仓。

### UNI-02 基本面与估值卡

该规则的材料获取、财报前瞻、电话会议、EPS/DCF估值细节遵循 [个股研究模块](07-stock-research-module.md) 的 RESEARCH-03 至 RESEARCH-12。技术结构与缓存遵循同文档 RESEARCH-01/02。

普通股采用明确的行业档案。记录营收及其增长、利润/利润率、经营现金流/自由现金流、现金与负债、稀释、估值及关键业务驱动，附期间、单位、披露时点、来源、变化方向和异常项。

每个档案声明必需指标和阈值表达式；只对适用指标评估。银行等特殊行业不能被非金融公司的净债务/现金流模型误判；未有适用档案时转人工研究，不自动放行。必要数据未知时保持 UNKNOWN，非必要字段可缺失但明确披露。

研究卡包含：购买逻辑、支持证据、相反证据、估值情景（假设与范围）、可观察的逻辑失效条件、下一复查日期。估值范围是情景估计，不是价格承诺；低估不豁免趋势和风险条件。

逻辑检查分为结构化规则与人工复查项。结构化规则以来源可核实的数据判断；人工判断记录作者、证据和时点。AI摘要提出的疑点先进入待复查，不能单凭生成文本就把“可能恶化”升级为已核实失效。账户风险退出不等待研究文字完成。

ETF 使用基金目标、跟踪指数、费用、规模/流动性、成分集中度、杠杆/反向属性和跟踪情况，不套企业利润指标。ETF 与股票采用同一账户风险框架。

### UNI-03 强势候选雷达

仅对通过基础可交易性检查的历史时点股票池扫描。计算配置的多个观察周期相对基准收益、行业相对表现、相对强度百分位、成交活跃度和离近期高点的距离；指标分别展示，综合排名权重、缺失值政策和版本透明。

状态以 [第二模块](08-trend-strategy-module.md) 为准：OBSERVING、PREPARING、SETUP_READY、BLOCKED、EXPIRED、ARCHIVED；允许有原因的退回/暂停，不能误解为只前进的链条。一个主观察记录可关联多个策略机会，汇总状态由有效子机会派生。首次观察、每次变化和阻塞原因留痕，避免只在大涨之后事后称“早已发现”。

强势且距离合理入场区间过远的标的标记 OVEREXTENDED，等待回调或新结构；不扩大最高买价。排名用于发现机会，不直接产生交易许可。候选列表限制展示数量，盘中不推送滚动涨幅排行榜诱导交易。

### UNI-04 支撑压力与区间

第一版使用可审计的历史高低点和区间高低边界，不默认声称拥有逐笔成交成本分布。

1. 高低点采用配置的左/右确认窗口；时点 t 只能使用已经走完右侧窗口的点。记录实际拐点时间与“被确认时间”。
2. 将过去窗口内已确认的相近点按 ATR 倍数容差聚合为区间，记录来源点、接触次数、最后接触和区间上下界；排序规则确定化。
3. 支撑/压力选取基于当前价格附近的有效区间；没有足够历史点时显示“无法形成可靠区间”，不由 AI 填补。
4. ATR 使用明确版本的真实波幅及平滑算法，价格序列按企业行动处理；图表、信号和执行价格之间转换口径一致。
5. 区间不是必然反弹/回落的位置。图上解释突破、回踩、失效的判定方式，历史图只能在当时确认之后显示该区间有效。

## 6. 第一版策略模板

以下是需要验证的候选规则，不代表已发现盈利优势。所有窗口、容差、周期和阈值都是策略配置；缺少必需参数时该模板仅可展示草稿。

趋势分类及适用性由 [第二模块](08-trend-strategy-module.md) 的TREND规则统一计算，各策略在其基础上追加自身条件。四个交易模板为STR-01、STR-02、STR-03、STR-05；STR-04为共用事件/隔离规则。策略匹配仅代表研究机会，后续仍须遵循PLAN与RSK规则。

### STR-01 核心普通股：基本面合格＋右侧回调

2026-10-26历史实现补充：用户要求优先完成具体技术买点并选择EMA20，后续修订以本节更新和专题为准；技术信号不代表下列完整核心策略及账户条件通过。

2026-10-29新增独立MACD图标1策略：12/26/9的DIF上穿DEA且两者≤0，当日收盘后直接提示买入。不得叠加EMA20回踩、5根红带期限、主趋势、同日转绿或次日确认条件。图标25/底背/二次金叉仍未接入，退出和仓位规则待设计；不生成成交。见[独立箭头策略](20-macd-reversal-discussion.md)。

2026-10-27修订覆盖上条技术细节：用户要求从明确上涨波段高点回到EMA20附近，再由紧邻下一交易日开盘/收盘守住确认。高点当天必须为绿带，先选窗口最高价再检查色带，不能改挑较低绿带高点。最新确定最多容忍5根连续红带，含回踩和确认日；第6根起本策略按下降处理并取消旧上涨资格。短暂转绿不能复活旧高点，须在最近超限日之后形成新高点，上涨起点不得早于该日，并通过原有上涨背景条件。技术信号不再要求突破前高、确认日EMA继续上涨或受旧追价距离过滤；价格与风险参考单列，仍不代表下列账户/计划要求通过。实现与可调初值以专题v5为准。

资金池：核心。目标：降低在下降趋势中仅因跌幅大而买入的次数，同时以结构性持有规则减少小赚即走。

入场条件按以下顺序全满足：

1. UNI-01 可交易；UNI-02 行业档案检查通过，研究逻辑和失效条件齐全且在复查有效期内。
2. 配置的市场环境门槛通过；如配置选择不使用环境过滤，仍保留风险降仓规则，并记录这一选择。
3. 完整日线 t 满足 close(t) > MA_long(t)，MA_short(t) > MA_long(t)，MA_long(t) > MA_long(t−slope_window)；参数满足 short < long，历史长度充足。
4. 最近 pullback_window 内价格触及在当时已知的有效支撑区间；未触发预设的结构失效条件。
5. 确认日收盘重新站上区间上界，并超过前一完整交易日最高价；其他量能过滤若开启必须单独满足。
6. 拟入场区间不超出配置的支撑距离/波动上限；到最近有效压力区间的空间满足策略要求。没有有效压力区间时不编造盈利目标，使用预先声明的无压力区间政策。
7. 通过 RSK-02/03、事件限制和计划完整性校验。最早下一适用交易时段触发。

风险退出参考来自已确认结构下界与配置波动缓冲，不因害怕亏损把止损挤进正常波动区；仓位按该距离反推。主策略不因下跌摊低成本。加仓仅允许预先登记的、结构重新确认后的新计划，总风险重新计算。

持有规则：基本面逻辑有效且未触发账户/单股风险条件时维持持有；浮盈达到某个小百分比本身不构成卖出信号。长期没有自动的一月到期限制。

退出优先级：账户风险处置 → 个股风险退出 → 已核实的逻辑失效 → 配置的趋势退出或组合再平衡。长期趋势退出在完整日线/周线确认，不混用机动策略的盘中波动规则。跟踪退出参考只能按确认后的结构提高，不能在下跌时向下放宽；企业行动引起的等价调整除外。

用户可以配置分批止盈或持有期，但必须在计划中预先定义比例、触发条件和剩余仓位规则；没有该配置时不得生成“小赚先跑”的默认卖出提示。组合集中度上升可触发再平衡，与主观害怕利润消失分别记录。

### STR-02 核心 ETF：产品合格＋趋势/回调

资金池：核心。普通非杠杆 ETF 采用 UNI-02 ETF 档案，趋势和回调条件可复用 STR-01 的价格结构模块，参数独立配置。

ETF 组合与直接持股合并检查行业、成分和主题集中度。产品目标/结构显著变化、无法可靠跟踪、风险条件或配置的趋势条件失效时复查或退出。不能因为名为 ETF 就默认低风险、无损失或适合满仓。

### STR-03 机动左侧修复：下降背景中的有限尝试

资金池：机动。用于保留用户有限的左侧偏好；要求主趋势已确认DOWN、策略显式启用、背景组合允许，可以在中长期趋势尚未满足STR-01时研究短期修复，但不能只凭跌幅触发。已确认RANGE的区间波段改由STR-05单独处理，未知趋势不放行。

入场要求：UNI-01 与该机动策略配置的基本面最低质量档案通过；已有历史支撑区间；完整日线重新收回区间下界并满足配置的短周期企稳条件；风险退出参考低于有效入场区间；最近可见压力区域提供足够的净风险收益空间；无重大未解决基本面破坏或配置禁止的事件风险。

短周期企稳条件在第一版定义为：收盘高于前一日最高价，且最近 configured_stabilization_bars 根完整日线未出现低于此前观察段最低点的新低。它仍可能处于中长期下降趋势，因此不视为核心趋势确认。

计划必须有区间目标、失效价、最大持有期限、最多分批数和合计风险。第一版可只启用单笔入场；启用分批时每档价量预登记。失效后不无限补仓，不把失败波段转成长线解套。

默认草稿期限语义为一个自然月：从首笔成交时点推算同日历日，遇月底缺失日期取当月最后一日；退出检查落到该日期或之后首个适用常规交易时段。用户可改为自然天数或交易日数。期限到达产生到期退出计划/提醒，不伪造已经成交；未能执行则进入逾期状态并持续计风险。

分批成交不能滚动延长原计划期限。重新入场需满足新的冷静期、研究和风险条件，保留前一交易段绩效。

### STR-04 模板隔离与事件处理

每个模板具有独立入场/退出参数；长期持仓不能误用机动止盈/期限。策略迁移按 BOOK-05 处理。

财报/重要事件政策可选：窗口内不新开仓、折减风险、人工复查后继续；已有长期仓位采用明确的事件持有与缺口情景，不默认每次财报全部卖出。事件时间未知时保守标记不确定，不能把“未查到”当“近期没有财报”。

### STR-05 机动区间波段：震荡下沿企稳

资金池：机动；支持通过适用质量档案的普通股，以及档案显式允许的普通非杠杆ETF。主趋势须已确认RANGE；上下边界按UNI-04与第二模块的区间确认规则形成，记录当时有效结构，不能事后重画边界解释失败。

入场要求：基础可交易性与研究条件通过；最近完整日线进入配置的下沿邻近区后收回下边界以上，并收于前一完整交易日最高价以上；区间未发生有效向下突破；计划入场价到上沿目标的净空间满足配置的风险收益要求；通过事件政策和账户/机动预算校验。接近下沿本身不构成买点。

风险退出参考为下边界扣除配置波动缓冲；区间目标为预先记录的上沿附近退出区域，分批比例、确认条件、最大持有期限分别配置。机动期限与分批不滚动延长的语义沿用STR-03，但不复用其下降背景条件。既有持仓的风险退出不能等待新趋势分类确认。

有效跌破下沿时原区间机会失效，不继续按震荡低吸加仓。向上突破导致区间策略不再适用时重评原计划；若研究趋势策略，须建立独立新机会和计划，不自动提高原目标或将机动仓改成长期仓。用户显式迁移仍遵循BOOK-05并保留历史。

## 7. 提醒和复盘

- **ALT-01 提醒内容**：证券、计划/持仓、触发条件、触发数据时点、当前价格与允许区间、风险状态、建议核查事项。市场发现提醒与风险提醒分层。
- **ALT-02 去重与失效**：按事件/计划版本/条件状态转换去重；冷却周期、升级与恢复提示可配置。旧版本与过期计划不得继续发送入场通知。
- **ALT-03 延迟与故障**：延迟行情显著标识，不宣称实时；数据或任务失联发送健康提醒，停止不可靠入场提醒。数据恢复重算，过期信号不补发成“现在可买”。
- **ALT-04 确认不等于成交**：消息送达、用户已读、计划确认、券商成交分别记录。用户未回复不等于执行，也不构成自动下单授权。
- **REV-01 绩效口径**：使用含现金、浮盈亏、分红、利息、费用的账户净值；时间加权收益用于策略/基准比较，资金加权收益用于个人资金体验；入出金不计收益。实际已扣佣金、交易税费与预扣税均计入标准净收益，并可单独展开；未知个人税负不推算，不宣称完整个人税后收益。另做税前比较时明确展示加回项，不与实际净值混用。
- **REV-02 资金池分账**：核心、机动、待分类分别统计，内部转账不当盈利；其和须能与总账户对账。策略迁移保留原段损益，不能把亏损转给新策略。
- **REV-03 行为指标**：计划覆盖率、无计划开仓/加仓率、未按计划退出率、配置放宽次数、止损后换股率、过期持仓数；盈利/亏损分开看，不能只奖励赚钱的违规交易。
- **REV-04 退出复盘**：统计持有期间最大有利/不利变动、实际退出与原规则回放差异。事后最高价不是应当卖到的位置；不能用未来价格反向评价当时合理决策。反事实回放明确标为模拟并计成本，不能宣称可实现额外收益。
- **REV-05 评估边界**：按市场环境和样本量报告胜率、盈亏比、回撤、换手和净收益。少量样本、遗漏证券或数据不足时明确不足；不为了达到年度收益目标过拟合。
