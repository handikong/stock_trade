## 1. 展示与命令

默认依次显示股票/行情时点、数据概览与缺口、技术表、两期财务、前瞻与指引、估值及外部简析。参数、全部拐点、ID、哈希和长JSON移入详情，原始档案不删。

```bash
.venv/bin/stock-research GOOG
.venv/bin/stock-research GOOG --cached
.venv/bin/stock-research GOOG --details
.venv/bin/stock-research GOOG --cached --details --facts-limit 0
.venv/bin/stock-research GOOG --json --output data/my-goog.json
```

cached不联网/计算；details展开完整旧明细，与json互斥。facts-limit仅控制details原事实，默认40、0全部，不影响JSON或摘要表。output按选定格式新建，拒绝覆盖。日志stderr、结果stdout不变。

RESEARCH_DISPLAY_TIMEZONE默认Asia/Shanghai，可改有效IANA时区；只改摘要显示，存储/JSON仍UTC，交易日不转换。details原证据保留UTC标签。

## 2. 数据口径

技术面展示现价区间、最近各3个支撑/压力候选，并保留最近已确认角色，候选不能冒充确认，评分不是概率；均线/ATR保留报价或调整价尺度。默认摘要不发布stale区间/估值，旧结果在详情保留。

两期财务按单季/累计/全年/期末时点、准则和单位分行。累计保留起点，不直接环比、不拼造单季/同比，多条同口径记录提示查详情。货币和股数以亿作显示尺度，EPS保留每股单位，缺失为“—”，原始精度不改。

前瞻中一致预期、修订、趋势独立展示；0q等标签不自动绑定目标期/GAAP，过去日程不当未来事件。管理层已人工核对指引独立列出。外部评论不当财务事实或风控通过。

## 3. 独立估值v2

算法automatic-valuation-draft-independent-models-v2只复用归档SEC批量数据；TTM仍用上一财年＋本年累计−上年同期，加权稀释股数按天数重建，不增财报下载/AI。

- 当前PE只依赖有效报价和完整正TTM盈利/稀释股数，不依赖DA、WACC、增长或历史PE最低样本数。
- EPS×PE另需可比增长、足够历史当时可知PE及三个有效情景，不需DCF专属字段。
- DCF在自己分支读取经营基线、DA、资本开支、营运资本及有来源的匹配WACC，不依赖历史PE样本下限。

共同适用范围保持：已知美元公司、SEC US-GAAP、非金融/地产模板、行情新鲜完整、TTM/财务年龄及拆股口径可用。不是任何缺数据都能计算；机械假设未变，不自动当指引。

components.pe/eps/dcf各记draft/missing及原因，partial标缺口，缺失模型为null。分支内三情景整体校验；仅PE可用也留档，缓存命中继续警告。旧v1留存并标stale，配置/来源/算法/估值日变化重算。CLI/研究/原页面兼容eps=null/dcf=null。
