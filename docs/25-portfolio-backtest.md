## 1. 交付范围与执行模式

新增公共`backtest.run`、`PortfolioReplay`与`stock-backtest`命令，使用本地MG7行情，复用原买点、共同退出状态及初始保护线。独立模拟现金/持仓/成交/应收款，输出完整交易配对、每日净值、跳过机会和期末状态。不会写研究数据库、真实持仓或成交，不调用yf、财报或DeepSeek。

用户前轮已确认：**真实环境只分级预警，手动选择退出；历史回测按确定规则模拟退出**。本次落地的是后者，报告mode=HISTORICAL_SIMULATION、simulated=true、real_orders_allowed=false。实盘账户、持仓登记/导入、人工卖出确认及按真实持仓持续预警尚未实现，不能把本次模拟成交当作这些能力已完成。

10,000 USD只属于这次研究账户，不修改实际本金或风险基准。第一版为一个共享模拟资金池；未接原设计的真实核心/机动90%/10%账本，不擅自把两套技术策略分配到真实资金池。

## 2. 配置与命令

默认参数在`config/backtest-policy.json`，所有金额/比例使用十进制文本：

| 项目 | 本次研究模板 | 说明 |
| --- | --- | --- |
| initial_cash / currency | 10000 / USD | 用户确认，可通过--cash改本次金额 |
| symbols | MG7 | 配置顺序就是同日不同股票的资金竞争顺序，固定且不看未来 |
| history_start / start / end | 2026-01-01 / 2026-03-01 / null | null终点取各股和日历的共同完整截止 |
| max_positions | 5 | 同一股票最多一份模拟持仓，不加仓 |
| max_security_fraction | 0.20 | 单股买入成本（含买费）≤初始资金20%，涨价不强制卖出 |
| minimum_cash_fraction | 0.10 | 新买入不得侵占初始资金10%的可用现金 |
| per_trade_risk_fraction | 0.005 | 每笔计划风险预算50 USD |
| total_planned_risk_fraction | 0.025 | 已持仓＋新买入计划风险≤250 USD |
| principal_loss_fraction | 0.05 | 固定本金保护参考线9500 USD，不按盈利/跨年重置 |
| gap_reserve_fraction | 0.005 | 另保留50 USD净值缓冲，不重复计损益 |
| fixed_fee / fee_fraction | 0 / 0.0001 | 每边固定费0，成交额0.01%，不是券商报价 |
| slippage_fraction | 0.0005 | 每边0.05%价格偏差，非拟合值 |
| sale_settlement_sessions | 1 | 卖出净款等待1个交易日才可用，是模拟假设 |
| stopout_cooldown_sessions | 1 | 保护线止损后下一完整交易日不新开该股 |
| strategy_priority | EMA_PULLBACK, MACD_ICON1 | 同股同日优先前者，不重复买入；不代表优劣判断 |

除资金与币种外，以上均是透明可改的研究初值，不是已确认生产参数或收益最优值。不因回测不到15%而强行调参。


## 3. 数据和价格口径

所有股票要求预热起点到共同终点交易日齐全、日期有序、OHLC有效、币种明确为USD。缺行情不联网也不静默减少股票池；缺交易日不跨日期取下一条价格；未支持的回测期拆合股直接拒绝。本次只支持现金多头整股，不支持融资、空头或外汇。

技术计算仍使用配置的调整/原价口径，并用完整预热期从首值递推。执行与估值使用行情缓存的原始报价OHLC；初始保护线按**信号日已知的调整价/报价比例**换回报价尺度后冻结，不每天用新的调整比例移动止损。保护线位置、买点和三项共同退出不为收益修改。

分红采用隔夜持股数量，在除息日计应收；缺支付日时不当作现金购买力。原价估值加分红应收，避免调整价收益与分红重复入账。未模拟税、现金利息、分红支付、停牌执行、实际券商购买力；现有复权档案不是当时完整可得的历史快照，固定MG7也有当前成分选择限制。

## 4. 成交与仓位顺序

每个完整交易日：

1. 到期卖出款转可用现金；隔夜持股按已知分红计应收。
2. 执行此前收盘确认的模拟卖出：次日开盘基准减卖出滑点。
3. 其余已有持仓开盘低于保护线，按开盘减滑点模拟退出，不能回填较高保护价。
4. 按固定股票顺序与同股策略优先级处理上一日买点。开盘基准加滑点，重新校验预算/持仓并可减量；这是研究执行假设，不保证真实开盘集合竞价可执行。
5. 检查日内最低价是否严格跌破已冻结的报价保护线；新开仓也检查。开盘已触及/跌破保护线的入场请求直接跳过，不先买再伪造更优退出。
6. 收盘三项状态同时偏空，预约下一交易日退出；新买点只排下一交易日，不用当天收盘成交。
7. 记录日终可用现金、未结算卖出款、应收分红、持仓市值、净值和回撤。

同股已有持仓时新买点仅记录跳过，不加仓，也不因明天计划卖出就预排重买；多个股票抢资金按配置顺序，不按未来收益筛选。买入立即消耗共享现金/预算，不能每只股票分别使用一整份1万美元。期末没有下一交易日的信号保留待执行，未退出持仓按末日收盘估值，不强平伪造完成交易。

仓位用Decimal向下取整，同时受以下最小值约束：

- 每笔计划风险预算；
- 组合风险上限减已有持仓从当前开盘标记价到保护线的风险及退出费用；
- 当前净值减固定本金保护线、缺口保留和已有风险；
- 可用现金减现金保留；
- 单股投入成本上限及持股数量上限。

新交易风险包含买卖滑点与双边费用，数量不足1整股就跳过。风险线更远时减少股数，而非收紧止损来凑数量。净值跌到本金参考线附近使新增预算不足时不再开仓，但不会虚构已有仓位已卖出；跳空仍可能造成超过计划的损失，5%不构成现实保证。完整行业/ETF重叠和压力情景风控仍未实现。

## 5. 报告和会计口径

报告保存每笔买卖的原信号日、模拟成交日、股数、参考/含滑点价格、冻结保护线、费用、原因和盈亏；跳过机会保存原日期与原因。期末净值＝可用现金＋未结算卖出净款＋应收分红＋持仓市值。

用会计恒等式校验净值变化＝已结束交易现金价差净损益＋未退出持仓市值减买入成本＋全部应收分红；异常直接拒绝报告收益。该校验是生产计算边界，不是独立测试脚本。最大回撤仅按日终净值计算，不涵盖日内低点。胜率/盈亏比只统计已结束交易，区间收益不冒充年化或未来预测。
