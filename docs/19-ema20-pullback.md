## 已确认的规则

1. 前面存在明确上涨波段，价格曾明显高于EMA20，所选高点当天必须为原始绿带（默认EMA10/20/9色带）。不要求连续多日绿带。
2. 从该波段高点回落，在T日回到EMA20附近。
3. 紧邻的下一完整交易日T+1，开盘≥T日收盘时EMA20，收盘≥T+1日收盘时EMA20；等于也通过。
4. 回踩日、确认日均可为红带或绿带，不依赖旧主趋势PASS。不要求突破前日高点，不要求阳线、上涨比例或确认日EMA继续上行，允许确认日盘中短暂跌破。
5. 连续红带最多5根，第6根起本策略按下降处理，候选与确认均失效。回踩日为第5根、确认日为第6根时，不产生信号。超过期限后转绿不能恢复旧高点，必须重新形成上涨波段。

信号在T+1收盘后才成立，历史列表日期是T+1，不回填到T；最早T+2交易时段才能依据完整信号研究执行。缺少T+1时仅展示候选。T+1开盘或收盘不满足则该T候选失败，不能等数日后上涨再补记成功；后续新T候选可重新接受各自的次日确认。

## 上涨波段与附近的计算口径

红带上限5根由用户明确指定；其余波段数值门槛是透明可调的初值，不是经收益验证或为某个日期拟合的最优参数。EMA独立配置，默认20；ATR复用项目Wilder ATR配置。

| 配置 | 初值 | 含义 |
| --- | --- | --- |
| peak_lookback | 20根 | 在T之前20根完整日线内找最高价，窗口不含T；同价取最近一天 |
| rise_lookback | 10根 | 在高点之前10根找最低收盘价作为上涨起点参考，窗口不含高点日 |
| min_rise_atr | 3.0 | 高点日收盘减起点收盘，至少达到高点当日3 ATR |
| min_peak_distance_atr | 2.0 | 高点日收盘至少高于当日EMA20达2 ATR，避免只有高位影线就被认作有效远离 |
| touch_tolerance_atr | 0.25 | T日高低价范围须与当日EMA20±0.25 ATR邻近区相交 |
| max_consecutive_red_bars | 5根 | 用户指定，最多容忍的连续原始红带根数；第6根开始失效，含确认日，可配置0～120 |

另外要求高点日EMA20高于上涨起点EMA20；T日最高价低于该波段高价，T日收盘低于高点日收盘。这是“先上涨、再从高点回落”的可解释定义，不要求每天连续下跌。采用此前已知的滚动高点，不借用未来才能确认的拐点。回踩日收盘可低于EMA20，没有沿用旧版“回踩期间不能收低0.5 ATR”的门槛。

完整候选历史至少为`max(ATR窗口+1, EMA周期)+peak_lookback+rise_lookback`，默认ATR14时为50根；确认还需下一根。因此2026年1—2月预热并不保证3月首日就有足够历史，早期不足如实输出。均线、ATR、开高低收采用同一调整价/原价口径。

先选窗口最高价，再检查高点日色带；若为红带则候选不成立，不跳过它另挑更低的绿带高点。高点色带缺失或无效时标记数据不足。JSON保留检查`PEAK_GREEN`与证据`peak_band_color`，命令行标明“绿带高点”；配置版本为`ema20-peak-pullback-v5`。

## 连续红带与波段失效

从完整预热历史逐根累计原始红带，按完整交易日而非自然日计数；遇绿带清零连续计数。第5根仍可检查买点，第6根收盘起本策略趋势为DOWN（下降），不回填前5根，不删除失效之前已经成立的历史信号。色带缺失时不能假设中断红带，相关判断为数据不足，并阻断旧背景延用。

保存最近一次超限红带日为`invalidated_through_session`；继续超限时该日期逐日推进，转绿时保留。恢复资格要求所选上涨起点不早于该日期、高点晚于该日期，并通过既有绿带高点、上涨幅度、EMA抬高和远离均线条件。这样允许使用最后一根超限红带日的低位作为新上涨起点，但不能复用旧高点或旧上涨起点。没有强制新高超过上个失效波段的价格，也没有新增连续绿带天数。仍按原窗口先取最高价，不能为恢复资格绕过窗口最高点。

回踩日与确认日各自检查红带上限及波段资格；不能因为T日通过，就跳过T+1新增的失效事件。短暂转绿只清零红带计数，不能清除失效记录。失效后保持下降标签，直到新上涨背景满足上述条件；恢复背景不等于立即买入，仍需回踩及严格次日确认。

本次范围为`--strategies`中的EMA回踩策略趋势与资格，逐日输出`pullback_background`和策略`background`，包含方向、中文标签、红带根数、上限、失效日期与当日失效事件；不改写原始色带或旧版结构主趋势快照。命令行新增超限转为下降的日期列表，以及最新状态和未通过原因。未增加价格结构失效门槛或真实持仓退出。

## 信号去重和价格参考

同一高点波段连续多日通过确认只记录首次，后续显示“该机会已触发”。普通价格条件中断后，新的T及其T+1重新满足可再次产生新信号；红带超限导致的波段失效则必须重新形成上涨背景。更换高点仍须通过失效日期检查。去重包含预热期，不在展示起点重新发信号；不等同于已成交或自动加仓。

- `entry_reference`：确认日收盘。
- `entry_max`：收盘＋配置的0.25 ATR，仅为入场参考上沿。
- `invalidation_price`：高点之后至确认日的最低价－配置的0.3 ATR；无有效正价格时为空。
- `signal_levels`及`signal_levels_as_of`：保留首次信号当时的价格；`levels`为当前日判断，不能用它放宽真实持仓止损。

本版删除回调策略原有“离EMA不超过1.5 ATR”“离前高突破门槛不超过0.75 ATR”的买点过滤。最大风险距离配置保留为价格参考检查，不影响技术形态是否命中；未接入的账户风控不会被显示为通过。止损、成本、成交和持仓跟踪均未模拟，不预设小幅盈利自动止盈。

## 命令与输出

```bash
.venv/bin/stock-trend NVDA --method futu-macd --start 2026-03-01 --strategies
.venv/bin/stock-trend AAPL --method futu-macd --start 2026-03-01 --strategies
```

每条历史新买点附带高点日期/价格、回踩日期/最低价/EMA，以及确认日开盘和收盘各自比较的EMA。最近一日展示未通过条件和新候选。`--end YYYY-MM-DD`指定历史终点，`--json`提供完整逐日依据，`--output`另存且不覆盖已有文件。`--strategy-check`仍是别名。

配置为`config/band-strategies.json`；`--strategy-policy`可另指定。JSON策略ID由`GREEN_PULLBACK`改为`EMA_PULLBACK`；该策略的route_by为`PRIOR_UPSWING_AND_PRICE`。旧自定义配置中的lookback、max_break_below_ema_atr、max_distance_ema_atr、max_distance_trigger_atr已移除，需改为上表的波段参数；旧字段会明确报错，不静默忽略。

策略只复用趋势绑定的确切行情快照，结果在内存计算，可随命令导出；不抓财报、不调用DeepSeek、不新增观察池或成交。命令本身沿用行情缓存流程，缺档案时可能获取行情。`--cached`仅要求已有匹配趋势，买点始终按当前策略参数重算，不读取旧版策略结果。算法与参数版本均随结果导出。

旧v4自定义配置缺少`max_consecutive_red_bars`时默认补5，并在导出的完整配置中体现。可用`--end 2026-06-01`定位用户提供的旧信号，查看连续红带与失效检查；本轮没有运行此命令，不声称已核实该日实际根数。

## 用户核对清单

- 普通均线附近震荡或没有明确前期上涨/远离均线，不能仅靠触及EMA产生信号。
- 所选高点为绿带才能形成候选；高点为红带不通过、色带缺失为数据不足，不能改挑较低绿带高点。高点为绿带且其他条件满足时，期限内的回踩或确认转红仍可通过。
- 连续第5根红带不单独阻塞买点，第6根立即转为下降并失效；T为第5根、T+1为第6根，即使开盘/收盘守住EMA也不能确认。
- 超限后转绿、旧高点移出窗口或换成另一个旧高点，均不能复活失效前上涨背景；新起点和高点须满足失效日期约束及原有条件。
- 红带计数包含预热期；修改展示起点不重置计数或失效记录。未来第6根红带不能删除此前第5根已成立的历史信号。
- 高点、上涨起点均须早于T，确认只使用T+1；追加未来数据不能改写此前结果。
- T+1开盘低于T的EMA，即使后来收盘收回也失败；收盘低于当日EMA同样失败。
- 开盘/收盘守住，但盘中低点跌破、收阴、没突破前高或色带为期限内的红带，都不单独否决。
- T+1尚未到来或未收盘只显示候选；不能凭T+2反弹把失败T候选补成买点。
- 连续确认不重复发信号，原信号价格冻结；中断后的新回踩可重新判断。
- NVDA05-05、AAPL09-01是对照案例，不硬编码为必选/必排日期；若同波段更早有满足条件的确认，也应正常展示，不能为了指定日期删除早先信号。
