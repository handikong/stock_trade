# 富途美股热榜股票池

2026-11-07启用。请求[富途公开美股行情页](https://www.futunn.com/quote/us)使用的 `/quote-api/quote-v2/get-heat-list`：`sortId=17&orderBy=1&marketType=2&offset=0&count=100`。只取前100条候选，不向后补至100只股票。先取得公开页面提供的匿名会话，再按页面的请求格式访问接口；不使用登录账号。结果是当时的富途热度榜快照，不是 Yahoo 成交量榜。

只接受美股且富途 `instrumentType=3` 的股票。排除所有 ETF（含普通、杠杆和反向ETF）及其他非股票类型。校验满100条且至少一只可入池，按股票代码去重，富途 `BRK.B` 等类股代码转为现有行情系统格式。接口报错、限流、缺页或不能确认类型时保留旧关注池。接口是富途网站端点，网站改版或限流时可能不可用；不会静默换成另一榜单或重试到成功。

首次成功时，在同一数据库事务里把关注池替换为筛出的股票（原池交集保留），其余旧关注软移出；不动持仓、行情、策略信号和投递档案。以后只追加不在活动池的新上榜股票，下榜不移除，明确手动移出的股票不恢复。每日同步结果包含候选、被排除、真实新增和移出代码。

默认每天北京时间06:00执行，包含周末和美股休市日，10:00结束当天补跑。只在有新增时发送一条飞书卡片。按北京时间日期归档，同日重复执行不会重复修改名单或已确认送达的消息；飞书失败或结果未知不自动重发。正常美股交易日先处理热榜，再更新新关注池日线；07:00继续等日线阶段完成后扫描。首次热榜失败时暂停从旧指数池自动扫描，后续热榜失败则沿用已建立的池。

```bash
# 立即预览，不改池
.venv/bin/python -m stock_research.futu_heat_cli preview
# 立即应用到当前数据库；第一次会替换旧池
.venv/bin/python -m stock_research.futu_heat_cli sync
# 如需对本次真实新增发飞书
.venv/bin/python -m stock_research.futu_heat_cli sync --send
# 查看最近入池记录和发送状态，不联网
.venv/bin/python -m stock_research.futu_heat_cli status --json
```
