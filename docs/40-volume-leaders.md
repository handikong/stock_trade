# 每日美股成交量榜与关注池扩充

2026-11-07：从美股市场取每个交易日成交股数前50，按代码合并到现有关注池，历史上榜成员持续保留。此功能不把原关注池重新排序冒充市场榜，也不发送榜单消息。

北京时间06:00盘后行情任务先通过 [yfinance 自定义筛选](https://ranaroussi.github.io/yfinance/reference/api/yfinance.screen.html) 请求 Yahoo Finance 覆盖的美国股票（`EquityQuery(region=us)`），按 `dayvolume` 降序取最多100条候选，从中保留前50只有效且不同的股票。按常规交易时段成交股数，不按成交金额或均量；不套用纳指/标普指数池的20日成交金额或价格门槛。排序范围以 Yahoo 的股票覆盖为准，不能称作交易所全量核算榜。即使原池为空也可从榜单新增。

使用现有交易日历和盘后窗口；校验50只不同股票、正整数成交股数、成交股数排序及每条报价的美东交易日。若为空、过期、字段无效、限流或不足50只，保留旧榜及关注池，原关注池日线处理继续并留任务警告（行情网络请求仍遵守同一 Yahoo 限流冷却）。榜单取自盘后供应商快照，不能保证供应商之后不修订。休市不重复处理；不跨日补抓旧榜。

榜单、每日快照、首次/最近上榜日期、最近排名与成交股数、累计上榜次数和关注池增量在同一事务保存。同一交易日重启复用已保存榜单，股票不重复入池，上榜次数不重复加。下榜不自动移除；指数来源自动停用过的股票可因上榜恢复，明确人工移出和来源不明的历史移出不自动恢复。指数同步不清除仍在关注的历史上榜成员。

新增股票参与当轮日线更新，07:00沿用该轮扩充名单；仍只扫描目标日已有完整有效K线的活动成员。行情、策略、飞书条件保持原逻辑。

在 `config/post-close-schedule.json` 中用 `volume_top50_enabled` 开关控制（本项目默认配置为true；旧自定义配置无该字段时默认为false）。重启并保持系统后台常驻后生效：

```bash
.venv/bin/python -m stock_research.schedule_cli fetch-leaders
.venv/bin/python -m stock_research.schedule_cli fetch-leaders --date 2026-11-06
.venv/bin/python -m stock_research.schedule_cli leaders
.venv/bin/python -m stock_research.schedule_cli leaders --date 2026-11-06
.venv/bin/python -m stock_research.schedule_cli leaders --json
.venv/bin/python -m stock_research.schedule_cli status
```

`leaders`只读最新成功榜单及上榜次数，日期以美东为准；失败日原因看`status`。每日成功榜存档至`research_snapshots`，类型`volume_leaders`。未运行服务、测试、实时抓取或发送。

`fetch-leaders`无需后台常驻，会立即从 Yahoo 请求最近完整交易日榜单并显示预计新增或恢复的股票；不修改关注池、不保存榜单、不触发扫描或飞书。沿用现有数据库与 Yahoo 冷却记录；遇限流可能写入供应商冷却记录。若来源已切换到未收盘的新交易日，返回错日提示，不用该榜替代完整日榜。可加 `--json` 输出结构化预览。

`leaders --date` 按美东交易日查已保存的榜单，不联网；没有档案就明确返回未保存。`fetch-leaders --date` 只校验请求日期是否为最近完整交易日，不把指定日期传给 Yahoo 回查历史。默认收盘后还等待30分钟；盘中报错会列出供应商报价日与目标日，方便区分错日与其他失败。未执行实时抓取或测试。

旧版本“含重复代码或非美国市场证券”合并提示已拆分：完全一致的重复成交量和时间只保留一条；明确标为其他市场或非股票的候选跳过，用后续名次补足。市场字段缺失时使用请求本身的 US 筛选；仍要求每条纳入记录为股票、同一目标交易日及有效成交量。重复数据相互冲突或筛选后不足50只时不入池；JSON含跳过项，日志显示计数。该报错修订未自行运行抓取或测试。

用户验收：V50-01 盘后目标交易日有完整榜且新增成员进入同一轮行情名单；V50-02 次日下榜不移出，重复上榜次数加一，同日重启不重复；V50-03 手动移出优先，指数同步保留活动榜单成员；V50-04 错日、不完整、休市或限流不改池；V50-05 空池可由有效榜单起步，榜单查询只读，不触发飞书。
