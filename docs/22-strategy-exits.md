## 1. 规则

公共纯计算方法`strategy_exits.attach_exits`接在两套买点计算之后，不改变买点筛选或去重。退出算法`signal-linked-technical-exits-v1`，汇总算法`multi-strategy-ema-v5-macd-icon1-exits-v1`。

| 策略 | 冻结初始保护线 | 指标退出 |
| --- | --- | --- |
| EMA_PULLBACK | 复用买点当时的invalidation_price：高点之后至确认日最低价－确认日ATR×stop_buffer_atr，默认0.3 | 买点日之后连续2根完整日线收盘严格低于各自的回踩EMA，默认EMA20；收盘大于或等于EMA清零 |
| MACD_ICON1 | 信号日及此前合计10根完整日线最低价－信号日ATR×0.3 | 买点日之后第一次本策略DIF下穿DEA：当日DIF＜DEA且前日DIF≥DEA；默认12/26/9，不限定零轴上下 |

两个策略都在当日最低价**严格低于**冻结保护线时触发价格保护退出。相等仅触线，不算跌破。开盘已经低于保护线额外标注，但不制造按保护线成交的记录。保护线优先，不等待EMA两天或MACD死叉；同日多个条件成立只产生一条退出，reasons保留全部原因。

EMA采用回踩策略独立ema_period，不混用色带均线；MACD直接复用箭头策略indicator，不用10/20/9色带代替12/26/9交叉。第6根红带仍只管理回踩入场资格，不单独触发退出。两套策略都没有固定盈利止盈、移动保本、移动ATR止盈、分批或持仓期限。

## 2. 技术跟踪与真实持仓的区别

- 每条买入信号独立建立跟踪项，以策略ID和买点日期关联。没有真实成交，不使用“实际买入/卖出价”“已平仓”“收益率”。
- 买点日收盘建立规则，**下一完整交易日**才开始检查，不能用买点当天早于信号确认的最低价触发退出。
- 同策略多个买点分别跟踪，可以同时存在；新信号不重置旧保护线，不假设加仓、重仓或已持仓。不同策略互不清除。
- 每个跟踪项首次退出后终止，不在后续每一天重复退出。退出当天仍可记录另一条新买点，二者日期关联清楚，不推导交易顺序或成交。
- 从预热起点开始跟踪，最后才按展示起点裁剪；因此退出可关联展示起点之前的买点。对应买点不一定已在股票池history中存档，退出自身保留原日期、保护线和来源。
- 保护线按买点当时数据冻结，不因波动加大、新低、窗口移动或新买点放宽。修改配置或复权数据后的重算属于新分析版本，不是修改真实交易止损。
- MACD信号可能在ATR或10根窗口不足时出现。买点仍保留，保护线标UNKNOWN且以后不补造；指标退出继续评估，输出提示价格保护缺失。
- 买点未退出只表示技术条件尚未触发，不等于实际持仓、仓位有效或账户风险通过。

本次全部使用日线：价格保护只能在收盘后事后识别当天是否破位，不能提供真实盘中监控或精确触发时刻。EMA/MACD退出在收盘后确认，最早下一交易时段参考执行；当日收盘仅作参考，不是卖出成交价。无滑点、费用、实际收益计算，未来回测不得拿当天收盘前尚未知的条件成交。

价格沿用同一原价/调整价口径，默认调整价；历史复权保护线不是可直接下单的实时报价，完整执行模块后续再处理。

## 3. 配置

`config/band-strategies.json`新增exits段；旧自定义配置缺段时补以下默认值并在输出保存完整配置：

```json
{
  "enabled": true,
  "ema_below_closes": 2,
  "macd_low_lookback": 10,
  "macd_stop_buffer_atr": 0.3
}
```

enabled可关闭本次全部技术退出跟踪，买点不变。ema_below_closes合法整数1—20，macd_low_lookback整数2—120，macd_stop_buffer_atr有限数0—10。EMA初始缓冲仍复用已有顶层stop_buffer_atr，EMA周期复用pullback.ema_period；没有第二套分歧公式。参数只是已选基准，并未验证其收益优劣。

## 4. 输出与历史

单股命令保持原用法：

```bash
.venv/bin/stock-trend NVDA --method futu-macd --history-start 2026-01-01 --start 2026-03-01 --strategies
```

增加“历史技术退出”和“最近一日仍在技术跟踪的买点”，显示日期、对应买点、冻结保护线、退出原因、收盘参考和判断证据。`strategy_results.signals`仍仅买点；新增exit_signals，逐日及latest新增exit_tracking/exit_signals，买点新增exit_plan。参数修改时重新计算，不读取旧策略退出结果。

股票池扫描自动接入，同一signals列表用event_kind=BUY/EXIT区分，另存buy_signal_count/exit_signal_count及最近技术跟踪项。新鲜度检查和历史标记沿用原规则：旧数据的退出不会冒充最新提醒，但仍可查历史。

```bash
.venv/bin/stock-watchlist scan --offline --history-start 2026-01-01 --start 2026-03-01
.venv/bin/stock-watchlist history --kind EXIT --symbol NVDA
.venv/bin/stock-watchlist history --kind BUY
.venv/bin/stock-watchlist last --json
```

沿用已有事件/修订表，不新增成交表。买点保留旧主键；退出主键为股票、策略、退出日、EXIT、原买点日的确定性哈希，同日多个原买点退出不合并。旧记录没有event_kind时按BUY读取，history筛选先过滤再limit。重复扫描不重置首次发现；规则修订不删除旧退出档案，history仍代表曾经发现，last才是那次范围内结果。
