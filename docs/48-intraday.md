# Go 盘中监控

## 部署

在项目根目录的 `.env` 加入下列配置，Key ID 和 Secret 只填在服务器。飞书沿用已有群机器人配置。

```dotenv
INTRADAY_ENABLED=true
INTRADAY_FEISHU_ENABLED=true
APCA_API_KEY_ID=在服务器填写
APCA_API_SECRET_KEY=在服务器填写
```

首次部署使用 `bash deploy.sh`，已经部署的服务器启用盘中监控或更新代码时使用 `bash update.sh`。两条命令都会按服务器架构选择 Go 官方安装包，核对 SHA-256 后安装到项目的 `data/deploy/go-toolchains/`，再构建 `data/deploy/stock-intraday`。当前版本固定为 Go 1.27.3，相同版本复用本地工具链。Git 更新包含新版 Go 配置时自动安装新版本。下载及编译完成后才重启后台。若先只看持仓行情，可设置 `INTRADAY_FEISHU_ENABLED=false`。 [Go 官方下载](https://go.dev/dl/)

打开「我的持仓」查看最新价格。价格列只显示金额，优先使用有效的 IEX 盘中成交，单股盘中报价不可用时显示收盘参考价。持仓市值和浮盈亏使用对应价格，报价尺度待核对时仅显示参考价。盘中汇总和持仓占比等待全部持仓的有效盘中报价齐备。收盘净值及其历史以每日收盘数据为准。运行日志沿用 `data/deploy/worker.log`。

若持续重连，在项目根目录执行 `grep 'Alpaca' data/deploy/worker.log | tail -n 30`。鉴权和订阅确认各有独立的等待时间。日志区分鉴权、订阅、心跳和行情读取，并记录可用的错误码或读取错误类型。出现「IEX 订阅已确认」后，再查看持仓页的行情时间是否继续更新。

## 交易时段与数据

- 复用 XNYS 交易日历，仅在美东常规交易时段连接，覆盖节假日、夏令时和提前收盘。北京时间 **02:00 起**停止发起盘中飞书请求。队列中的过期信号跳过，行情持续到收盘。截止前发出的请求，飞书实际显示时间由服务端决定。
- 一条 IEX WebSocket 订阅 QQQ、SPY 和实际 USD 持仓，去重后最多 30 个代码。超额时按持仓成本从高到低选入，未订阅的数量在页面标明。持仓名单变化约 20 秒内重新订阅，断线退避重连并用同一 IEX REST 数据补当日分钟线。
- Go 每 5 秒输出行情快照。以有效成交的时间检查新鲜度；最近没有成交、断线或分钟样本不完整时降级。保护位可用有效实时成交复核，普通结构等已完成分钟线。分钟线预留 35 秒接收迟到修订，再合成确认 K 线。确认周期内分钟有缺口就跳过该根。
- IEX 成交量只代表 IEX。量比对照最近五个常规交易日同一段时间，至少三段完整样本；样本不足时留空。缺少同尺度日线时价格仍可显示，涉及该日线价位的判断不通过。现价与前收盘差异达到 35% 时标记报价尺度待复核，避免疑似拆股触发旧价位策略。

## 提醒条件

| 类型 | 条件 |
| --- | --- |
| 止损复核 | 开盘即检查已登记且报价尺度可比的冻结保护位。过滤特殊成交，正常跳空触及也提示。仅导入数量和成本的持仓可能没有保护位。 |
| 关键位预警 | 默认等开盘 15 分钟。日线支撑下沿、前低、上升趋势线或 EMA20 被越过，且超过 0.10 倍日线 ATR 缓冲时预警。 |
| 减仓复核 | 有支撑或前低作为锚点，连续两根完整的确认 K 线收在缓冲线下方，实时价格仍在其下。缺少结构确认时保留预警。 |
| 支撑收回 | 盘中回踩已确认支撑区，最近两根完整确认 K 线与实时价用于判断是否收回支撑上沿。没有确认支撑时用前低，EMA20 也可单独提示收回。收线与现价均须站到缓冲上方。 |
| 突破回踩确认 | 前一根确认 K 线收在压力上沿加缓冲以上，后一根回踩缓冲区并收在关键位上方，现价仍守住且高于 VWAP。没有确认压力时参考前高。单次触碰压力不发。 |
| 止盈复核 | 仅对配置了止盈价且仍有浮盈的持仓。最近两根确认 K 线触及登记价和压力区后，收线与现价回落到压力下沿缓冲以下。 |
| 大盘同步走弱 | QQQ 和 SPY 均在各自 VWAP 与支撑参考下方，合并一条提醒并暂停普通加仓。 |
| 加仓复核 | 已有建议计划且有剩余股数。左侧看支撑回踩收回，右侧看突破后回踩守住且站上 VWAP。实时价仍在计划价带内才复用现金、本金风险、同向集中度和估值检查。全部持仓的有效盘中报价不足时暂停加仓。 |

支撑、压力、前高前低、EMA20、趋势线和 ATR 从上一个完整交易日的缓存准备，同一交易日复用。盘中普通提醒按美东交易日、股票、类型和价位去重。相距一个 ATR 缓冲以内的破位价或支撑收回价合并，预警升级到确认后可再发。支撑收回与突破只提示结构变化，加仓按原计划与风险检查独立复核。已尝试投递保存到 `DATA_DIR/intraday-notifications`，可在「推送记录 → 盘中预警」核对。发送结果未知时等待核对群消息。

截止时间、开盘等待、确认周期、报价时效和波动缓冲在 `config/intraday-policy.json` 配置，修改后重启生效。`take_profit_targets` 默认空白，可按美股代码填写美元止盈参考价，已有 `INTRADAY_POLICY_FILE` 可指向服务器自己的配置。

## 用户验收

- ID01 常规开盘后订阅持仓、QQQ、SPY，节假日等待。新增或移出持仓后核对列表，超出上限时核对被排除数量。
- ID02 检查实时市值与浮盈亏，区分 IEX 与收盘参考。核对断线、重连补线及无成交时的显示。
- ID03 核对保护位触及、普通预警和确认破位的时机，确认同一价位不会持续重复推送。
- ID04 有加仓计划时检查价带、剩余股数和保护位。大盘走弱、账户资料不足或价格超出价带时暂停加仓提醒。
- ID05 北京时间 02:00 前后核对飞书与投递档案，持仓价格继续更新至收盘。
- ID06 在 Linux x86_64 或 ARM64 上启用盘中监控后运行部署或更新，核对下载包架构、项目内的 Go 版本和构建产物。再次更新时复用工具链。下载、校验或构建失败时旧后台继续运行。
- ID07 核对重连日志能区分订阅确认超时、心跳发送失败和行情读取中断。重新订阅确认后检查 QQQ、SPY 行情时间是否恢复更新。
- ID08 开盘后核对含大写 `S`（股票代码）和小写 `s`（成交股数）的 Alpaca 成交消息能持续更新报价，不因字段大小写冲突触发重连。类型异常日志仅展示字段名和预期类型。
- ID09 核对美股持仓价格列只显示金额，盘中价、市值、浮盈亏与比例同步。编辑持仓后等待版本对齐。单股盘中报价过期及收盘后查看收盘参考价，汇总等待盘中报价齐全。
- ID10 核对跌破、收回、突破回踩和冲高回落四种形态。缺完整确认 K 线时不发新结构提醒。相近失守价合并一条，同一状态去重，减仓确认可单独升级。止盈复核只针对已填价的盈利持仓。
