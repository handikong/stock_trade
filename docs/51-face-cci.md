# FACE 笑脸抄底与飞书提醒

FACE 是独立的日线买点。按用户提供的富途公式实现以下抄底信号。

```text
N:=14;
TYP:=(HIGH+LOW+CLOSE)/3;
CCI:=(TYP-MA(TYP,N))/(0.015*AVEDEV(TYP,N));
COND01:=BARSLAST(CROSS(MA(C,10),MA(C,5)))>=8;
COND02:=CCI>REF(CCI,1) AND CROSS(CCI,-110);
COND03:=COND01 AND COND02;
抄底:DRAWICON(COUNT(COND03,5)=1 AND COND03,LOW*0.998,5),COLORRED;
```

- CCI 用典型价格的 14 日简单平均与同一窗口的平均绝对偏差。前一日 CCI 可等于阈值，当日须严格大于阈值。
- MA5 和 MA10 均为收盘价的简单平均。用预热窗口内最近一次 MA5 下穿 MA10 的日期计数，下穿当日为第 0 根。预热历史内未观察到下穿时，间隔未知。平均绝对偏差为零时，CCI 未知。
- 最近 5 根完整日线含当日。计数包含所有原始候选 `COND03`，包括先前被计数条件抑制的候选。窗口不足或候选次数仍不确定时，先不发信号。
- 所有指标沿用扫描窗口及其价格口径。与富途逐日对照时使用同样的复权方式和足够的预热历史。图标坐标 `LOW*0.998` 仅供比对。

默认由 `config/band-strategies.json` 的 `face` 段启用。CCI 周期、阈值、交叉间隔和计数窗口可配置，MA5/MA10 沿用原式。旧自定义配置缺少 `face` 段时保持关闭。用户同一段公式里的 RSI 顶底背离留作独立规则讨论。FACE 当前只产生买点，卡片把保护线显示为待确认。持仓买入计划、共同退出和组合回测仍沿用各自原有策略范围。

美股北京时间 07:00、A 股 09:00 的任务分别读取对应市场的扫描结果，沿用现有飞书机器人。只有目标交易日行情完整且信号仍有效才发送。历史回放用于比对，正式投递继续按股票、策略、交易日和目标机器人去重。卡片显示笑脸、上穿前后的 CCI 和均线交叉间隔。

```bash
# 查询单股历史信号，替换为你有行情缓存的股票和日期
.venv/bin/stock-trend NVDA --method futu-macd --start 2026-03-01 --strategies --strategy-details

# 查股票池扫描产生的 FACE 历史
.venv/bin/stock-watchlist history --strategy FACE

# 预览单股当前有效信号的卡片
.venv/bin/stock-notify NVDA --cached-research
```

## 用户验收

- FACE01 用同价格口径与同日线预热范围对照富途。均线下穿后第 7 根不通过，第 8 根允许。前一日 CCI 等于阈值且当日上穿时检查能否命中。
- FACE02 核对 5 根计数窗口。窗口内之前已有原始候选时，当天抑制。之前被抑制的原始候选也参与后续计数。平均偏差为零或历史不足时不生成信号。
- FACE03 扫描当前有效买点并预览卡片。确认美股和 A 股沿用各自计划，成功投递可查记录，同一信号重跑不会再次发送。
- FACE04 同一天 FACE 与原策略同时触发时保留各自事件。禁用 FACE 后原策略仍正常判断。
