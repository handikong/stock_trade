# 仓位管理与买入计划

## 操作

1. 「我的持仓 → 填写账户」录入 USD 参考本金、总现金、券商可用现金、允许本金亏损比例和自基准后累计外部净入金。参考本金由本人确认，亏损比例初值为 5%。交易盈亏不填进净入金。按券商余额定期核对，默认 96 小时后需要再次确认。
2. 「导入已有持仓」直接登记已有股数和成本，选填机动仓归属。录入和编辑可以校对持仓事实，已有持仓立即纳入下一笔评估。手工改数量后，旧计划保护位保留在成交历史，当前未绑定的股数按压力情景估算。日线缺失时先用「更新行情」。
3. 「评估买入」输入代码。有同股持仓时自动按加仓处理。网页给出建议执行、等待确认或拒绝。首仓要求目标日已有确认买点及可用保护位；左侧等触及支撑后收回区间上沿并收阳；右侧等连续两个完整交易日收盘高于突破位。后两档条件从计划日后开始验证，新开仓需先登记首仓。每档可查看买入价带、最多整股数、预警位、保护位、保护距离和计划损失。价格区间来自现有策略、完整收盘与已确认技术区间，缺有效证据的档位不自动补造。
4. 保存建议计划会预留三档中所有可执行的资金和风险。默认在信号后的第五个交易日收盘到期，期内可随时复核或取消剩余计划。原保护位失守或发生拆股时释放未成交计划额度。同股只保留一个活动计划。
5. 人工方案可覆盖技术、估值和组合的系统建议。填写股数、买入价、保护位与理由，先看占用、额外风险和同向持仓变化，再保存。现金需有近期核对记录并足以覆盖当前方案及其他活动计划。保存人工方案保留原评估及风险提示。
6. 到「买入计划 → 复核／登记成交」输入券商已发生的美东成交日、股数、价格及费用。现时复核用于提示，偏离计划的实际成交保留理由。确认后同一事务更新持仓、加权成本、现金、保护位和预留；若你已按成交后的券商余额对账，勾选现金已扣，避免重复扣款。止损与预警在账户风险详情用完整日线复查，最终由你操作。
7. 美股和 A 股的持仓行均可「登记卖出」。填实际成交股数、成交价、成交日及选填费用。卖出全部为清仓，卖出部分为减仓，剩余持仓成本均价按原均价保留。卖出净额入对应币种总现金，只有勾选券商显示款项已可用才同时增加美股可用现金。账户余额已包含成交时可勾选跳过现金变动。页面显示本笔已实现盈亏，并刷新当前持仓与账户估算。两市场的持仓行均可直接登记实际加仓，按加权平均更新成本。
8. 清仓会移出当前持仓，清理美股保护位并取消该股剩余活动买入计划。美股减仓先扣未绑定保护位的持仓，再按登记顺序扣减保护批次，剩余批次沿用原价位。旧批次缺少资金池标签时，剩余股数内保守保留其机动归属。成交作为记录留档，已保存的历史净值仍按原快照查看。「移除」用于更正持仓记录。
9. 两个市场的持仓页各有「交易记录」。可按证券代码、买入／加仓／减仓／清仓以及市场当地成交日筛选。列表按成交日倒序，显示成交股数、价格、费用、成交净收支、已实现盈亏及成交后剩余股数。已登记的旧成交也可查询。导入、编辑、移除等持仓对账操作只保留持仓变更记录。两市场首笔实际成交用「登记买入」，已有持仓从该行登记加仓。与美股买入计划关联的成交使用该计划的「登记成交」，以便同步计划余量。每笔实际成交只登记一次。

## 计算口径

- 净值＝总现金＋所有有效 USD 收盘市值。参考线＝参考本金×(1−本金亏损比例)＋累计外部净入金。建议新增风险上限看净值离底线的缓冲、已有保护风险、组合压力、已预留风险、单笔上限及大盘系数。持仓缺目标交易日有效报价时，净值及剩余额度明确待补。
- 本金亏损＝参考本金减去扣除累计净入金后的净值，最低为零；亏损比例＝本金亏损÷参考本金。账户显示该金额及比例，净值待补时亏损也显示待补。
- 已有仓位的保护风险从当前报价算到冻结保护位，另计费用和跳空余量；跌破后仍有真实持仓时采用更保守压力。未绑定保护位用历史最大五日跌幅、ATR 波动与缺历史保守值估算。组合压力按同一历史五日窗口计算各仓下行损失，不假定上涨仓会抵消；样本未齐时用各仓单独压力叠加。保护估算与历史压力取较高值，之后计入未成交计划；这些数字是情景估算。
- 同向仓比较已知行业标签、重叠日收益相关系数和下跌时同跌频率。已存 SPY/QQQ 相关成分名单只在资料近期时作提示，权重未知时仅凭成分重叠不把整只宽基基金算作同向集中。行业标签可扩展。进攻型看 ATR%、相对 QQQ 的 Beta、下跌日表现与已知进攻型 ETF，资料不足时按谨慎档计入。已有仓位、首仓及两档预留一起占用单股、同向、进攻和机动空间。
- 大盘优先读同一美股交易日的简报，使用 SPY/QQQ 强弱、临近压力、收盘破位和 VIX。缺同日简报时可由现有 SPY/QQQ 行情计算技术方向，VIX 缺失按谨慎档。大盘和组合风险控制新增额度，先确定技术保护位，再按最高允许价、现金、损失与集中度算整股数。
- 当前 USD 财年 EPS×Forward PE 情景参与报价比较，保留参考口径；数据缺失或过期要求等待，超过乐观情景价拒绝自动建议。ETF 使用技术与组合风险。正常计划按当前估值上沿限制拟买价。机动额度默认按参考本金的 10%，用于左侧加仓和 MACD 零轴下反转首仓，可在风险配置调整。
- `config/portfolio-policy.json` 内阈值是可改初值。默认现金预留 8%，单股 18%、同向 35%、进攻 45%，随大盘系数缩减；这些是各预算计算上限，不是固定推荐仓位或持股数。整股向下取整。每档风险包含费用、滑点预留及价格波动。缺口可能大于预留。
- 账户配置、评估输入及版本、计划、人工理由和成交追加留档。保存与成交使用同一账户写锁和版本检查。自动扫描、回测与实际券商下单仍为各自独立流程。

## 用户验收

- PA01 参考本金 125,000、5%、无净入金时，保护参考线显示 118,750 USD；增加净入金调整参考线，保留原亏损预算。
- PA02 导入无技术审批；已有持仓按实际数量参与风险，目标日价格缺失时剩余额度待补。
- PA03 同行业、同期同跌和进攻型风险均可解释；压力升高后建议股数缩小。ETF 仅有成分重叠时展示来源限制。
- PA04 技术或估值未齐时等待；可用风险、集中度或现金不足时拒绝；各档保护位与实际买入上限可复核。
- PA05 首仓及后续两档共享预算；拒绝重复活动计划；取消、超时或破位释放未成交额度。
- PA06 人工方案预览与保存保留原建议、理由和新增风险；不同窗口变动后要求复评。
- PA07 部分成交更新现金和加权成本、保留余量；已对账时避免重复扣现金。重复提交旧版本不得加倍入账。
- PA08 部分卖出后核对剩余股数、成本、已实现盈亏、净额和保护位；卖出全部时核对持仓行消失、总现金增加、原活动计划取消。超卖或重复提交不入账。
- PA09 核对美股未标为可用的卖出款只进入总现金。A 股加仓和卖出分别扣增人民币现金；勾选余额已含成交时不重复入账。两个市场的账户分别刷新。
- PA10 保护位在后续持仓详情可见，收盘破位时仍保留真实持仓，等待本人对账。
- PA11 登记买入、加仓、减仓和清仓后分别查交易记录。验证旧成交可见、两个市场互不混入，代码、类型和起止日期能组合筛选，清仓记录在持仓行消失后仍可查询。持仓导入不出现在成交列表。
- PA12 从美股持仓页直接登记首笔买入，再从持仓行登记加仓。核对现金和加权成本，分别按「买入」「加仓」筛选，并核对原买入计划登记的成交仍可查询。
