# 纳指100与标普500扫描股票池

2026-11-07补充：[每日成交量榜](40-volume-leaders.md)是关注池的独立累积来源。上过榜且仍在关注的成员不因后续指数同步被移出；手动移出仍优先。指数来源的门槛不用于每日成交量榜。

2026-11-05用户要求扩充扫描股票，并剔除冷门和低成交量股票。本次实现的是当前候选名单导入与流动性筛选，不是新的买卖策略。

## 规则与可配置参数

UNIV-01：纳指100与标普500候选合并，按证券代码去重；同一代码保留两个指数标签。不同股权类别仍是不同证券，例如GOOG与GOOGL均可能保留，不把它们的成交量相加。

UNIV-02：先把“冷门”具体化为近期流动性，不凭公司名气或新闻多少删除股票。默认截至最近完整美股交易日，连续20个交易日，日均成交金额近似值至少100,000,000 USD，末日收盘至少5 USD。每天以供应商未自动复权的收盘字段乘对应成交股数，再取算术平均；不是实际逐笔成交金额，也不是收益或可成交价格保证。这里不要求日均100万股，避免误删高价但成交金额充足的股票；不加追涨、行业或涨跌幅条件。

参数在`config/us-universe-policy.json`，可用`US_UNIVERSE_POLICY_FILE`替换。平均金额、最低价均为十进制字符串，金额用Decimal；请求间隔默认0.5秒。默认完整名单最长7个日历日需更新，明确资料日和真实取得日都检查，不能修改时间给旧名单续期。规则初值可调整，不代表已按历史收益调优。

UNIV-03：缺交易日、非USD/币种未知、无效价格或成交量、获取失败均为UNKNOWN，不伪装成低成交量或通过。新UNKNOWN候选不加入；已关注的UNKNOWN保留原状态，报告单独列出，避免网络故障清空旧池。所有结果都未通过时不应用名单。已有市场缓存窗口完整且截止正确时直接计算；否则仅请求20日流动性数据，单独存`universe_liquidity`快照，不冒充完整研究行情。后续06:00仍由正常行情入口补齐完整研究/策略K线。

UNIV-04：Yahoo全局限流沿用公共冷却；出现限流后本轮余下股票只读缓存，不连续轰炸、重试或force绕过。日线直接使用ticker.history并固定SDK时区适配器，只读取行情自带币种/时区，不请求证券身份、财报、电话会议、PE或模型。

UNIV-05：只有显式`--apply`写现有watchlist_entries；普通运行预览并保存评估/流动性缓存。自动管理成员不再合格或不再在有效来源中时软移出，历史行情、策略、投递和真实持仓保留。人工add/remove写入watchlist_state的独立us-index-universe控制记录，优先于后续自动同步；旧版已经移出的成员在首次导入时也不会被恢复。人工添加可明确保留筛选之外的股票；与门槛通过数分开展示。没有新增账户权限或多用户规则。

UNIV-06：扩大的关注列表由现有后台06:00及07:00任务按各自任务快照使用。这里不新增自动指数更新日程，也不在每次list或研究时获取全市场。重新筛选需执行本命令；当日06:00名单已经固定后再导入的新成员，下一次盘后周期进入计划任务。不会因本次导入立即扫描策略、发飞书或改变回测默认MG7组合。当前成分名单不能冒充历史成分，回测不得直接据此声称消除幸存者偏差。

## 使用

项目根目录：

```bash
# 实际筛选：已有完整近期缓存复用，缺失补近期日线；只保存报告，不改名单
.venv/bin/stock-universe

# 将合格股票写入当前关注列表；已有手动移除意图优先
.venv/bin/stock-universe --apply

# 只读已有价格缓存完成评估；可配--apply，但缺数据不会被补造
.venv/bin/stock-universe --offline

# 更新公开来源，再抓缺少的近期日线、筛选并同步；失败保留旧池
.venv/bin/stock-universe --refresh-members --apply

# 完整逐股结果输出
.venv/bin/stock-universe --offline --json
.venv/bin/stock-watchlist list
```

没有可执行入口时，等价使用`.venv/bin/python -m stock_research.universe_cli`。新环境安装入口已登记pyproject，现有虚拟环境补了启动文件，没有执行pip安装或测试。

需要代理时沿用用户提供的命令行配置：

```bash
export http_proxy="http://127.0.0.1:7897"
export https_proxy="http://127.0.0.1:7897"
```

新增候选数据只用于流动性筛选，网页暂时没有这些股票的完整研究/策略结果属于正常状态；后台06:00将获取完整K线，07:00才算买点。发送仍受现有有效期/去重/每轮消息上限约束，没有为股票数增加而取消上限。没有EPS/PE手工输入时仍明确提示基本面缺失，不补造推荐依据。

同步锁`data/universe/sync.lock`防止同机重复批次；最终名单应用另外使用现有watchlist.lock短事务，获取行情时不锁住网页增删。保存期间重新读取人工决定，避免导入覆盖用户刚作出的移除。状态metadata继续放现有watchlist_state，无旧表加列迁移。逐次报告追加`data/universe/universe-*.json`，包含来源、参数、目标交易日、平均成交金额、过滤原因、缓存/获取版本及真实变更。重跑复用截止匹配的流动性数据，不重置旧信号或通知去重。

CLI成功0；存在UNKNOWN或未应用错误为2；输入/持久化/配置错误为1；中断130。中断保留已存价格快照，未完成批次不应用股票池。
