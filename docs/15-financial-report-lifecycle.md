## 公共入口

`stock_research.financial_reports.process_financial_reports(security_id, *, force=False, analyze_reports=True, on_progress=None)`。

处理顺序：SEC财务和原文 → 可用备用财务 → 业绩附件 → 查找同财报版本的永久分析 → 无对应分析时调用DeepSeek。命令行和网页的普通刷新已经调用该入口。`security_id`是已保存的证券ID，调用方先初始化存储、建立或读取证券；返回`steps`及`warnings`，每一步的缓存/跳过/缺失状态独立保留。

```python
from stock_research.financial_reports import process_financial_reports

# 普通查询：完整财报档案复用；已有AI结果直接返回；首次完整取得财报时可分析。
result = process_financial_reports(security_id)

# 后续日历适配器：仅在来源实际发布或修订之后同步，再由公共方法判断是否有新内容。
# 日历订阅/事件适配器尚未实现，这里是供其调用的既有公共方法。
result = process_financial_reports(security_id, force=True)
```

公共入口不获取行情/动态预期、不确认预计财报日期、不创建日历订阅；调用方可分别刷新相关数据。未来收到“日期变更”“预计即将公布”不能调用发布分支。`force=True`仅要求人工/发布后的来源同步，**不强制重跑AI**；来源仍返回旧报时直接复用旧分析。实际新报需要先取得原文与结构化数据，不能只修改日历时间就标成已有新报。

目前数据获取仍复用已有SEC同步与归档能力，尚无直接接受日历推送文件及结构化财务的专门外部事件接口。

## 分析生命周期

| 情况 | 行为 |
| --- | --- |
| 没有财报原文 | 先获取；仍没有则等待，不让AI猜测 |
| 财报取得完整、没有本地对应分析、已配置DeepSeek | 首次分析并永久保存 |
| 同版本财报已分析 | 直接复用；重复查询、重复发布通知均不请求模型 |
| 新季度、修订或新补充财报材料实际保存 | 为未覆盖的新版本分析；通过的分段可继续复用，旧档案/分析保留 |
| 仅行情、预期、EPS修订、日程或确认事件变化 | 更新独立数据块，不重跑财报分析 |
| 仅模型、提示版本、token配置或估值假设变化 | 已完成分析继续复用，不因配置升级重复付费 |
| 新增/扩大研究范围，出现未曾分析的财报版本 | 分析未覆盖范围；已有结果覆盖的范围缩小直接复用，并保留原分析的实际范围 |
| 获取阶段有警告，资料尚未补齐 | 不自动付费分析半份材料；保留可读旧结果 |
| 分析失败或进程中断 | 已完成分段和尝试记录保留；普通查询/重启不自动重复付费，`--analyze`或分析按钮手动继续 |
| `--force`人工同步 | 财报原文同版本复用；AI同版本仍复用 |
| `--cached`只读查询 | 不获取、不分析、不改写档案 |

版本清单使用材料类型、期间和原文内容哈希，不使用抓取时间、股价、动态预期或模型参数。相同内容从不同URL重复归档不会仅因新ID产生新付费分析。旧分析通过已保存的`source_ids`恢复清单，无需重新调用模型迁移；新分析保存`document_manifest`、`report_key`、`cache_policy`、`retention`。已有更大范围分析覆盖当前全部原文时复用原报告，不谎称其原始范围已经缩小。

同一来源/类型/期间取最新保存版本；改版后不会同时把同一URL的历史旧正文作为当前必须重读的材料。财报修订保留原档，不覆盖历史。

采用每证券文件锁防止命令行和worker在同一主机、同一DATA_DIR并发重复请求；`analysis_attempt`在开始付费前持久保存版本。进程退出释放锁，尝试记录仍阻止普通查询自动重试。该锁适用于本项目macOS/Linux单主机部署，不是跨主机分布式锁；当前仍不支持多副本计算部署。

## 旧动态信息与展示

财报草稿可能含分析当时的市场预期、日期或事件。它们保留原来的时点与证据，不把旧摘要中的预期更新成今天值，也不为此重新调用DeepSeek。最新数据在独立预期/日程区块。

`analysis.stale`仅表示当前需要的财报版本/期间未被原分析覆盖；`analysis.dynamic_context_changed`单独提示动态上下文变化，前端和命令行均说明“不因此重新分析”。分析保持草稿，不等于财务和引用语义已经核实。

命令行`--analyze`用于首次/新版本分析或手动继续失败任务；已有同版本完整结果仍返回缓存，没有“强制重新付费”含义。使用`--document-id`时会校验资料属于当前股票；已有分析覆盖所选版本则复用原结果。
