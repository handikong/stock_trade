- 参数均可配置；账户币种由使用者确认，但不阻塞以证券报价币种运行的研究模块。
- 程序获取/保存原始材料和计算估值，AI基于证据分析；缺资料不能补造。
- 财报前预期、公司指引、实际业绩与模型假设分开；电话会覆盖正文与Q&A。
- 趋势、观察状态、计划与真实持仓独立；第一版不自动下单。
- 未接入数据或未完成能力明确标记，不以模拟数据宣称已运行。
- 第一、第二模块分别按F类、T类验收场景推进；其余模块待后续讨论。
