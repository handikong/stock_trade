# 单股买入到卖出的配对过程

日期：2026-10-31。用户要求直接看到一只股票“什么时候买入、什么时候卖出”的完整过程。本轮调整展示与结构化归档，不改变买点或共同退出规则，不新增真实交易、资金管理、仓位或回测。

## 1. 默认展示

`stock-trend ... --strategies`现在默认按股票、策略ID和原买点日期配对，一条过程包含：

1. 买入信号日期、收盘参考价和冻结保护线。
2. 中途一级/二级预警、退回与撤销的日期，按时间排列。
3. 对应卖出信号日期、收盘参考价和退出原因；价格保护破位附开盘和最低价。
4. 若截止日尚未退出，显示“跟踪中”和当前状态；若退出跟踪关闭或不支持，明确标注，不显示为应当继续持有。

这里的买入/卖出日期均是技术信号日期，不是实际成交日期；收盘参考不是实际成交价。买点和指标退出收盘确认，最早下一交易时段使用；日内保护线破位只由日线事后识别。不会凭参考价差计算真实收益。

每条买点仍独立跟踪：同一股票不同策略或不同日期的过程可以重叠，不视为加仓，也不先假定一买一卖之后才能买入。完整交易约束后续再接。

## 2. 窗口与配对

公共方法`strategy_flows.build_flows`从已有完整预热计算结果配对，**先配对，再筛选展示窗口**。配对键是同一股票内的策略ID＋原买点日期，不按“离得最近的买点”猜测。

- 在窗口内买入的过程展示。
- 起点之前买入、窗口内退出的过程，补回原买点和此前预警，并标注展示起点前资料。
- 起点之前买入、截止时仍在跟踪的过程，同样补回。
- 起点之前已经退出的完整过程不列入本窗口。
- 数据只限当前预热起点之后。没有更早资料不补造买入历史；缺少对应买点或同一买点出现多个退出时明确报错。
- 未退出、未知和未启用跟踪分别标记；没有信号时明确为空，不生成样例交易。

## 3. 命令与兼容

```bash
# 单只股票完整过程
.venv/bin/stock-trend NVDA --method futu-macd --history-start 2026-01-01 --start 2026-03-01 --strategies

# 需要检查公式和逐项条件时，保留原详细展示
.venv/bin/stock-trend NVDA --method futu-macd --start 2026-03-01 --strategies --strategy-details

# 股票池按股票分别展示完整过程
.venv/bin/stock-watchlist scan --offline --history-start 2026-01-01 --start 2026-03-01
.venv/bin/stock-watchlist last
```

`--strategy-details`必须配合`--strategies`。JSON继续保留原signals、exit_signals、exit_alerts及逐日证据，增加flows和flow_format_version=`paired-signal-flow-v1`。flows是当前分析版本的配对视图，没有独立交易账本。

股票池扫描保存同一flows视图，数据截止、旧行情/缺口警告仍显示。last读取的旧批次若没有flows，继续显示旧事件视图，不跨版本拼接历史；重新扫描才得到新展示。history保留事件查询语义，不更改事件主键、首次发现时间或修订规则。

不指定--start的股票池扫描仍按现有最后可用日窗口，仅展示与该窗口相交的过程；要看3月以来所有已结束和未结束过程，应指定--start 2026-03-01。完整过程内可能包含历史买点或旧预警，不能把展示本身当作今天的新提醒。
