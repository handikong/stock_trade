## 1. 当前有效规则

每条买入信号继续独立跟踪，买点条件不变。下一完整交易日起评估，保护线严格跌破优先；正常趋势退出要求当日收盘以下三项同时为真：

1. 原始色带为红：DIF10/20＜DEA9（实际周期沿用色带配置）。用户称偏多色带为“蓝带”，代码继续保留既有GREEN/RED枚举。
2. EMA5＜EMA10，周期在exits中独立配置，不用MA、不用回踩EMA20。
3. MACD12/26/9的DIF＜DEA，不限定零轴上下；周期沿用macd_arrow配置，即使关闭该买入策略，也保留其指标供共同退出判断。

比较均为严格小于。相等时该转弱条件不成立。看当前状态，不要求当天刚刚交叉、不要求三个事件依次发生、不要求至少等待三天。全部数据完整且三项同时为真，直接确认退出；有关键值缺失则为UNKNOWN，不能默认成立。独立价格保护仍评估。

| 红带 | 快EMA低于慢EMA | MACD DIF低于DEA | 层级 |
| --- | --- | --- | --- |
| 否 | 任意已知状态 | 任意已知状态 | 0：撤销/尚未形成共同预警，其余条件仍显示 |
| 是 | 否 | 任意已知状态 | 1：一级预警 |
| 是 | 是 | 否 | 2：二级预警 |
| 是 | 是 | 是 | 3：确认技术退出 |

层级每个收盘重新计算。EMA5收回或等于EMA10而色带仍红，退回一级；MACD收回或等于DEA而前两项仍为真，退回二级；色带恢复偏多或两条色带线相等，撤销共同预警。单根阳线不自动视为“反包”。

开始评估时已经红带，直接查看第2、3项；不等待重新转红。MACD可能先死叉而EMA5尚在上方，此时保留其状态；以后EMA5落到下方且其余仍为真，直接退出。若MACD提前金叉，则须等其重新处于偏空状态。三项当天齐备可以从0直接退出，预警等级不强制逐日经过。

## 2. 冻结保护与跟踪边界

初始保护线沿用两策略现有规则：EMA回踩使用买点当时的失效参考（高点之后至确认日最低价减当日ATR缓冲）；MACD箭头使用信号日及此前合计10根最低价减信号日0.3 ATR，均可配置。线一经建立，不因新买点、新低、波动增大或窗口移出而放宽。

当日最低价严格低于保护线，即记录技术退出，不等三项确认；相等不算跌破。若同日价格保护和三项共同确认都触发，只保留一个退出事件，价格保护为首要原因，reasons保存二者。保护线未知继续明确提示，不后来补造，但可评估三项退出。

买点日只建立跟踪，显示PENDING；从下一完整日线开始判断。每条买点独立，新信号不覆盖旧线，不假设加仓。每跟踪项首次退出后停止，不因以后转强撤销已保存的历史退出，也不自动重新买入。新的买入信号可以建立新跟踪。

预热期参与全部计算和跟踪，最后裁剪展示日期。参数/复权数据重算属于新分析版本，不能据此改写真实交易。此处没有真实持仓、资金、成交或收益计算；日内破位仅由日线事后识别，收盘指标退出最早下一交易时段参考执行，不能用保护线或当日收盘虚构成交价。

## 4. 输出和使用

```bash
.venv/bin/stock-trend NVDA --method futu-macd --history-start 2026-01-01 --start 2026-03-01 --strategies
.venv/bin/stock-watchlist scan --offline --history-start 2026-01-01 --start 2026-03-01
.venv/bin/stock-watchlist history --kind EXIT --symbol NVDA
.venv/bin/stock-watchlist last --json
```

单股输出新增预警升级/退回/撤销日期、原买点、当前层级，以及红带、短EMA、MACD的数值和状态；退出另列。JSON逐日exit_market_state保留三项判断，exit_tracking保留各买点当前层级，exit_alerts只记录未退出跟踪的层级变化，不在同级每天重复预警。直接退出列入exit_signals，不再额外产生重复预警。

股票池扫描保存exit_alerts和当前各跟踪项；current_exit_alerts仅在通过既有行情新鲜度、完整性检查时包含当天变化。其余标历史/待复核。预警变化存在扫描记录，history --kind EXIT仍只看确认退出，不混入一级/二级预警。没有外部消息推送。旧last档案仍可读取，不把旧规则结果改名为新版。
