# 用户富途指标：色带、主趋势与回踩管理

日期：2026-10-24。用户提供富途公式，并明确“绿带看偏上、红带看偏下，震荡另判”。本次在既有AAPL K线核对任务中新增可选方法并实际运行，不新增test文件，不获取财报或调用AI。原三族方法仍可用于对照，默认入口未替换成尚未完整定义的三态分类器。

2026-10-25更新：用户要求优化“大绿带中的短红带”，并由用户重新运行。已增加独立主趋势状态机，保留原始色带与信号。新版仅完成代码阅读和逻辑推演，没有运行、没有新增测试文件或更新下方v1实际图。规则与参数见第7节。

## 1. 使用方式

```bash
stock-trend AAPL --method futu-macd --start 2026-03-01

# Python模块入口无需更新editable安装
.venv/bin/python -m stock_research.trend_cli AAPL \
  --method futu-macd --history-start 2026-01-01 --start 2026-03-01

# 完整逐日值、四条件和被FILTER抑制的信号
stock-trend AAPL --method futu-macd --start 2026-03-01 \
  --json --output data/AAPL-futu-macd-another.json

# 只读匹配的已保存指标
stock-trend AAPL --method futu-macd --start 2026-03-01 --cached

# 原三族方法对照
stock-trend AAPL --method three-family --start 2026-03-01
```

富途方法当前要求`--start`，`--history-start`默认展示起点当年1月1日，`--end`包含当日。预热和FILTER均从历史起点开始递推，最后才裁剪展示；先裁剪展示再开始FILTER会改变结果，禁止这样实现。已有本地展示行情直接复用；`--force`仅手动同步行情，不调用财报/AI。

`--policy`默认使用`config/futu-macd-policy.json`，与旧三族配置独立，不读取旧配置中的SMA、ER或结构门槛。配置包含长周期10/20、信号9、短周期3/10、FILTER 10和价格字段。所有周期可修改且校验快周期小于慢周期；价格字段可选`adjusted_close`或`close`，默认沿用本次K线核对使用的调整收盘价。原始收盘价仍是本地供应商档案，不保证与富途行情一致。

日志仍走stderr，报告走stdout；`--output`不覆盖旧文件。退出码0只表示计算/读取完成，警告为2，不代表盈利、趋势确认或风险许可。

新版仍使用相同命令；普通查询因算法/参数变化重算主趋势，不需要`--force`重新下载行情。首次不要加`--cached`，旧v1结果不匹配新键。已有命令入口可直接使用；若终端未激活虚拟环境，在项目根目录用`.venv/bin/stock-trend`。可导出新的文件名，例如`data/AAPL-futu-macd-pullback-20261025.json`，不要覆盖旧结果。

## 2. 公式与语义

```text
DIFLONG  = EMA(CLOSE,10) - EMA(CLOSE,20)
DEALONG  = EMA(DIFLONG,9)
MACD     = 2 × (DIFLONG - DEALONG)
DIFSHORT = EMA(CLOSE,3) - EMA(CLOSE,10)
DEASHORT = EMA(DIFLONG,9)  # 保留用户原文；等于DEALONG且未参与条件

COND1 = CROSS(DIFLONG,DEALONG)
COND2 = MACD[t] > MACD[t-1]
COND3 = DIFSHORT[t] >= DIFSHORT[t-1]
COND4 = DEALONG[t] >= DEALONG[t-1]
原始信号 = COND1 AND COND2 AND COND3 AND COND4
图标信号 = FILTER(原始信号,10)
```

- `DIFLONG >= DEALONG`为GREEN、`UP_BIAS`偏上；小于为RED、`DOWN_BIAS`偏下。相等时按原公式归绿，不增设死区或三根确认。
- 色带是两条线之间的填充，与DIF是否高于零轴、当日K线红绿不同。DIF/DEA同为负时也能转绿，这不能单独解释为长期牛市反转。
- 四条件信号只在金叉当天检查。它不是持续趋势状态；不能等待箭头才改变色带。
- FILTER仅抑制信号：保留一根后删除随后N根内的信号；被抑制的事件不延长抑制期。第N+1根可再次保留。N按实际K线根数，不是自然日。保存`raw_signal/signal/filter_suppressed`及最后保留信号日。
- 默认EMA递推为`alpha=2/(N+1)`，第一项以首个输入值初始化；CROSS按当前`A>B`且上一根`A<=B`实现。首根没有REF数据，四条件都为false，不伪造交叉。
- 原文`DRAWICON(...,DEALONG,4)`保留图标编号4与DEA位置。诊断图用金色三角表示该事件，并非富途4号图标的逐像素复刻。

四条件并非四份独立证据：金叉意味着MACD从非正转正，因此COND2随之成立；按同一DEA的EMA递推，金叉也包含DEA上行的关系，COND4与COND1重叠。短DIF不下降是额外过滤项。代码仍保留四条原始条件，便于用户和富途逐日核对，没有擅自删除。

## 3. 不预设震荡与交易含义

原始色带继续输出`bias`。新版逐日记录另外输出`trend.current_trend`及阶段，不伪装成旧三族方法的确认结果。主趋势当前只产生UP/DOWN或空方向，震荡保持`range_assessment_status=NOT_EVALUATED`。主趋势失效管理已实现，买卖、真实持仓风险、仓位和策略许可仍未接入，顶层`trend_dependency_ready=false`，每条主趋势`new_risk_allowed=false`。

色带提供方向证据，四条件保留为独立事件，震荡仍需继续设计。不能因为用户给了上涨图标，就自行反推一套下降图标、强制持有10天或拿死叉自动下单。

## 4. 来源、复现边界与持久化

富途官方[指标脚本说明](https://support.futunn.com/topic541)介绍脚本与函数库，但本次取得的公开页面没有完整给出首值初始化、CROSS等值及FILTER边界的实现细节。EMA递推、REF、CROSS、FILTER的同类公式语义参考[迅投官方系统函数](https://knowledge.thinktrader.net/docs/vba/system_function.html)，它是另一厂商的原始文档，不能冒充富途内部实现证明。

因此本次是按明确记录语义进行的公式复现，尚未与用户富途的相同股票、周期、复权、历史长度逐点对齐。1—2月39根预热不保证与富途更长历史的EMA完全一致，接近交叉时尤其要核对；不会违反仅使用2026年行情的约定，偷偷用更早数据消除差异。仅有短历史时给出警告，不用缺失价格补零。

公共方法：`futu_macd.calculate(bars,params)`、`futu_macd.evaluate_timeline(...)`；主趋势逻辑在`macd_trend.assess_trend`。数据库独立使用`kind=indicator_futu_macd`，首版算法`user-futu-macd-band-and-signal-v1`，当前算法`user-futu-macd-trend-with-pullback-v2`。复用现有按证券锁、市场缓存和交易日完整性校验；缓存键包括所选行情、预热/展示起止、参数、共享ATR/拐点窗口、递推/过滤语义、算法、日历版本及价格调整说明。固定历史不受实时行情TTL影响，`--cached`只读匹配记录，没有则提示先计算。未完成K线不参与，重复查询不累计事件。

## 6. 后续用户验收场景

## 7. 主趋势与回踩/反抽状态机（2026-10-25，未运行）

本次优化针对“短暂红带不能立即当作上涨破坏，但也不能把持续下跌永远解释为回踩”。原色带、四条件与FILTER不改，另外逐日维护主趋势和有效结构保护位。所有日子只使用当时已知数据，后续恢复不回填为之前已确定的回踩。

### 7.1 输出及进入

- 原色带仍在`daily_intervals`和逐日`bias/band_color`，主趋势另在`trend_intervals`、`trend_latest`及逐日`trend`。
- 主趋势方向为UP、DOWN或空，另有`CONFIRMED/CHALLENGED/PENDING/INSUFFICIENT_DATA`。阶段包括方向确认中、上涨/下降延续、回踩/反抽观察、转弱观察、恢复、失效和等待收复结构。
- 第一个方向要连续满足同向色带进入条件，并取得可用保护位才确认，默认2根；不等待箭头。结构不再要求两组高低点全部形成，不使用ER作为门槛。
- 两线等值仍按原公式画绿带，但主趋势层不把等值作为新的方向证据；已有方向转为动能等值观察。
- ATR与备用保护位所需完整历史不足时显示数据不足。默认至少`max(ATR_WINDOW+1, fallback_lookback+1)`根，默认21根；EMA初始化限制继续保留。

### 7.2 保护位及冻结

上涨初始保护位优先从回看窗口选最近可用、当时已右侧确认的低点，下降选高点。当前收盘必须位于相应结构的有效一侧。没有可用确认拐点时，允许使用今天之前完整N根的最低/最高价，明确标记`PRIOR_WINDOW_EXTREME`备用来源，不冒称确认拐点。

拐点和ATR复用`price_features.py`，窗口来自已有`PIVOT_LEFT/RIGHT`和`ATR_WINDOW`。若MACD选原始`close`，结构和ATR也改用原始OHLC映射后计算，不能混用调整价。策略/仓位风险金额未接入。

```text
上涨失效线 = 低点 − break_buffer_atr × 选定时ATR
下降失效线 = 高点 + break_buffer_atr × 选定时ATR
```

锚点和失效线持久保存在每个状态里：不会因旧点滚出观察窗口就消失；不会因当天ATR上升而自动放宽。趋势同向时只有之后新确认、日期更晚、价格与缓冲后失效线均更有利的拐点可收紧保护。逆向观察期间冻结锚点，不调整。先检查旧线是否失效，再考虑收紧新锚点，避免先换锚点掩盖破坏。

### 7.3 回踩与反抽

上涨遇红带、下降遇绿带且旧保护位有效时，主趋势保留背景方向，判断状态为`CHALLENGED`，先显示回踩/反抽观察，不确认反向趋势，也不放行新增风险。

```text
两线间距 = abs(DIFLONG − DEALONG) / ATR
```

默认逆向连续至少3根且间距至少0.10 ATR，或逆向累计到10根，即升级转弱观察。升级本身不等于已经反转。深度用两线差，不是已乘2的MACD柱；也不把红带持续天数单独当作下降结论。

如果原方向色带恢复，旧结构仍有效且没有触发下述反转路径，直接标记上涨/下行恢复，再继续原趋势，不要求重新发现两组高低点。恢复当日才记录恢复，不回填过去区间。

### 7.4 两条独立失效路径

**结构路径**：完整日线收盘严格越过冻结失效线，当天立即撤下原方向，不等待色带或确认根数。若反向色带进入条件已连续满足，且可建立新保护位，可以当天确认新方向；否则方向为空、等待确认。不会为了继续显示上涨而强行等待反转完成。

**持续反向路径**：即使旧保护位尚未破坏，逆向色带至少5根、当前两线间距至少0.20 ATR，且价格连续2根在慢EMA外的反向0.25 ATR位置，也撤下原方向并评估反向确认。

```text
上涨转下行价格证据：收盘 <= EMA20 − 0.25 × 当日ATR
下降转上行价格证据：收盘 >= EMA20 + 0.25 × 当日ATR
```

配置若改变慢EMA周期，上式使用配置的慢EMA，不固定20。连续价格计数只在对应反向色带期间累积，不从未来或不相关的先前时段借根数。先前已观察到的逆向色带进入计数可用于切换当天，不从那天额外再等待一遍2根；新方向起点仍只在实际达到条件的当天生效。

价格破坏后等待反向确认期间，若价格已回到旧失效线以内、又无持续反向价格证据，暂停反向候选，不能仅凭滞后的色带再确认新方向。

这些是价格趋势的研究失效规则，不能冒充真实持仓止损。个股/账户风险退出独立运行，不等待上述确认；本轮没有实现下单或保证本金损失不超5%。

### 7.5 破坏后的原方向恢复

保护位实际被突破后，原方向不能仅凭色带转回立即复活。上涨须先收复原低点加恢复缓冲，下降须跌回原高点减恢复缓冲，再连续满足进入条件。恢复缓冲按破坏当日ATR设置并冻结。确认新方向后结束该次等待，旧失效事件仍留在历史字段中。

### 7.6 可配置的初始模板

以下是未运行验证的研究初值，不是根据本次AAPL收益率或成功转折倒推的参数：

| `trend`字段 | 初值 | 含义 |

| confirmation_bars | 2 | 初始/重新进入的连续根数 |

| fallback_lookback | 20 | 无可用拐点时，之前N根极值备用 |
| break_buffer_atr | 0.3 | 保护线缓冲，选定时冻结 |
| reclaim_buffer_atr | 0.3 | 破坏后原方向收复门槛，破坏时冻结 |

### 7.7 用户重新运行的核对重点

1. 原始色带、四条件和FILTER结果应保持原公式口径，主趋势允许与当日色带不同。
2. 有效上涨背景下短红、结构未破且未满足持续反向条件，应显示回踩受挑战；之后转绿才能记录恢复。下降对应反抽，不能把它们事后全标为已知正常回踩。
3. 失效线越过应立即撤下原方向；不得通过延迟确认、切换锚点或放宽ATR缓冲隐藏破坏。
4. 旧点滚出60根窗口应保留锚点；收紧只能使用当日已确认的新结构，且不得松动失效线。
5. 持续红带且价格确认走弱应能升级/切换；只有红带较长但价格不配合时不能硬判下降，显示受挑战，震荡仍待独立研究。
6. 破坏后短暂回升到旧失效线附近时，不应立即确认反向趋势或恢复原方向；原方向须收复恢复门槛并重新确认。
7. 固定终点/追加数据时，逐日数值与当时状态应一致；最终区间末日可以延长，不能回填早期判断。

本次未执行上述场景或新版命令，没有生成v2实际结果。由用户运行核对；第5节v1图与数据不得冒充本次回踩层已验证结果。
