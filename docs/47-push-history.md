# 飞书推送记录

工作台「推送记录」默认展示最近 30 个北京时间自然日，按日期倒序分组，组内从新到旧。可按类型筛选，选择具体日期可查询更早的档案。点开一条记录查看正文和投递异常说明。每页 50 条，可继续加载；同一日期跨页时合并到原分组。

| 类型 | 收录范围 |
| --- | --- |
| 大盘推送 | 大盘日报、周一开盘计划、周报 |
| 个股推送 | 策略买点、退出预警、退出条件、手动发送的研究快照 |
| 关注推送 | 富途热榜首次重建和新增股票通知 |
| 持仓复盘 | 工作日复盘，分批卡片分别记录 |
| 盘中预警 | 保护位、破位、加仓复核和 QQQ、SPY 同步走弱 |
| 连通性测试 | 使用显式发送选项的飞书测试 |

每次尝试分别记录，包括显式重试。飞书已接收表示机器人返回成功。发送中超过五分钟仍无确认时，页面按结果未知显示。无信号、无新增、仅预览及投递前跳过的项目不列入。

后端复用已有投递表、任务结果、富途每日档案和手动投递 JSON。后续定时推送写入发送时间和卡片，旧档案缺少投递时间时使用归档更新时间并标记为估计。旧档案缺少卡片时尝试使用原报告重建，字段不足仍保留状态。正文仅以纯文本显示，较长正文在列表中截取。查询不会写入档案或请求飞书，无需迁移数据库。

## 用户验收

- PH01 打开「推送记录」，核对不同推送类型、北京时间分组、日期倒序及正文。
- PH02 按类型和指定日期筛选，查看无记录提示。超过一页时核对同一天的记录归入同一组。
- PH03 查看已有发送成功、失败和结果未知的档案，核对每次尝试的状态。仅预览、跳过及无新增的记录不应出现。
- PH04 核对一条新版定时推送的时间及卡片正文，以及旧记录的估计时间提示。
