# 实际持仓工作日复盘

北京时间周一至周五08:00入队，当天12:00前可补跑。使用现有后台Worker和最近完整的美股日线；周一或休市后沿用上一个收盘时，卡片标明数据日期和下个美股交易日。实际开始时间随后台队列顺延。只评估活动的实际持仓，独立于关注池与个股信号；无持仓记录空报告。后台复用完整缓存，缺目标日时只补活动持仓和必要的SPY、QQQ日线，遵守现有供应商冷却。

卡片按紧急程度排列。逐只展示最近完整收盘、近五日复权涨跌、EMA20/50方向、最近有效支撑和压力、已有冻结保护位及一项操作建议。候选区间标为待确认；资料缺失保留原股票并列为待补。

| 建议 | 判断条件 |
| --- | --- |
| 止损复核 | 已登记持仓的冻结保护位曾触及，或无浮盈时原三项共同退出确认。保护位优先，触及后仍保留实际仓位，提示核对券商执行情况。 |
| 止盈复核 | 有浮盈且三项共同退出确认，或反抽此前已确认的压力后转弱，同时有放量或二级弱势。压力附近仍强时继续观察。 |
| 减仓复核 | 收盘明确跌破此前确认支撑；或者实际持仓集中度超当前阈值且市场或个股走弱；或者触及本金底线且该仓为进攻型或集中持仓。 |
| 可考虑加仓 | 已保存的非人工计划中有一档通过最新复核且价格仍在允许范围，或今天出现买点并通过完整买入评估。给出价带、最多股数和保护位。多个提示共用账户额度，需逐只复核。 |
| 继续持有或资料待补 | 当前没有已确认的调整条件则继续观察；缺目标日行情或退出指标时明确提示待补。 |

退出规则复用现有红带、短EMA与MACD共识。结构破位按当时已知的区间和仓位配置ATR缓冲检查。复盘使用确定性规则，计划和账面持仓保持独立，操作由本人确认。

飞书使用现有机器人，默认开启持仓复盘和发送。每张最多八只，同一天按卡片批次留档。发送前核对持仓、现金、计划及行情版本；若数据变动，停止发送旧建议。已发送的批次去重，失败或结果未知停止后续批次并保留本地报告。`FEISHU_MAX_MESSAGES_PER_RUN`控制每轮消息上限。卡片只展示证券、行情价位和操作建议，不包含账户现金、本金或现有持股数量。

```bash
bash update.sh
# 立即看缓存复盘，不更新行情或发送
.venv/bin/python -m stock_research.schedule_cli holdings-brief --preview
# 查看最新归档及飞书状态
.venv/bin/python -m stock_research.schedule_cli holdings-brief
# 指定北京时间报告日
.venv/bin/python -m stock_research.schedule_cli holdings-brief --date 2026-11-09 --json
```

配置在`config/post-close-schedule.json`，包括`holdings_brief_enabled`、`holdings_brief_time`、`holdings_brief_until`、`holdings_brief_feishu_enabled`。若已有自定义`POST_CLOSE_SCHEDULE_FILE`，需合并对应字段。该任务和关注池的买点推送各自去重。

用户验收：HB01 工作日执行、沿用收盘日期准确；HB02 只处理活动持仓；HB03 保护位优先、普通触压不提前止盈；HB04 加仓复用最新估值和账户限制；HB05 缺项或部分获取失败仍保留报告；HB06 同日重启、飞书结果未知和持仓变化不造成重复或过期投递。本次仅代码审阅，未启动服务、运行测试或实际发送消息。
