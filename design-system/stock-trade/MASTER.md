# 见微 · 持仓与研究工作台

对象是个人美股盘后决策，页面首要任务为理解自己已录入的持仓，再进入扫描及研究。用户最新将A股推迟；保留不可操作的市场入口。本次不开发注册/登录、多用户或规则编辑。

沿用原生HTML/CSS/JavaScript＋Go静态入口＋FastAPI，不引入新的前端构建依赖。UI资料库两次设计检索均倾向营销门户/深色OLED，与此任务不符，未直接采用其版式；以下为针对现有产品制定的方案。

- 画布#F3F6FA，表面#FFFFFF，正文#20354B，侧栏#20374C，强调#19776F，分隔#DEE6ED；盈利#147568、亏损#B64D54，状态均同时配文字/正负号。
- 标题使用Avenir Next/PingFang SC系统字体，正文使用系统无衬线，金额使用SFMono-Regular/Consolas等宽及tabular-nums，不依赖外部字体网络。
- 左侧固定导航＋顶端市场切换，主体按内容使用宽表和较窄的辅助列。首页展示真实持仓，不填演示收益或虚构图表。
- 视觉记忆点为“持仓构成”：相邻的细比例条与对应持仓行同色，表达已录入股票间的市值构成。只有有效报价齐全时显示占比，不冒充含现金的账户仓位。

```
侧栏      市场 / 美股 USD                              搜索股票
          我的持仓                                   添加持仓
          市值 · 成本 · 浮盈亏 · 股票数量
          持仓明细表                          持仓构成
          空状态给明确添加入口，未知数据用—，不显示假零
```

扫描页显示可编辑名单、后台任务、最近真实结果；研究页显示估值、支撑压力和技术依据，并提供七字段JSON预览/确认。K线只在后台计算，不在前端显示。旧停用财报/AI操作移出页面。

所有交互使用原生按钮/表单/dialog，标签可见、键盘可达、焦点清楚，加载与错误有反馈，尊重减少动画。小屏侧栏变为顶部导航，复杂表格仅在自身容器滚动；不让整个页面横向溢出。全部文案中文。按用户约定只做代码逻辑审阅，未启动应用、浏览器或截图验收。
